## Struttura generale

- <span class="c-dato">**1° pilastro**</span> → <span class="c-def">AVS + AI + PC</span> → obiettivo: <span class="c-tesi">minimo vitale</span> → sistema: **<span class="c-def">ripartizione</span>**
- <span class="c-dato">**2° pilastro**</span> → <span class="c-def">Previdenza professionale (PP/Casse pensioni)</span> → obiettivo: <span class="c-tesi">tenore di vita</span> → sistema: **<span class="c-def">capitalizzazione</span>**
- <span class="c-dato">**3° pilastro**</span> → Previdenza privata (3a/3b) → obiettivo: integrazione individuale → <span class="c-warn">**non è assicurazione sociale**</span> → sistema: capitalizzazione

## AVS — Assicurazione Vecchiaia e Superstiti

- **Regime** → <span class="c-def">universale (tutta la popolazione residente)</span>
- **Obbligo contributivo** → dai <span class="c-dato">21 anni</span> ai <span class="c-dato">65 anni</span>
- **Rendita mensile** → min <span class="c-dato">CHF 1'260</span> · max <span class="c-dato">CHF 2'520</span> · media ~<span class="c-dato">CHF 1'870</span>
- <span class="c-tesi">**Solidarietà verticale** → chi guadagna poco riceve rendita proporzionalmente più alta</span>
- **Rendita per figli** → <span class="c-dato">+40%</span> della rendita AVS (figli minorenni o agli studi)
- **Finanziamento** → 3 fonti:
  - Prelievi su salari e redditi
  - Contributi pubblici (Confederazione + Cantoni)
  - Redditi da capitale (fondo riserva <span class="c-dato">Compenswiss ~50 mld CHF</span>)
- **Fondo riserva** → garantisce autonomia finanziaria di <span class="c-dato">almeno 1 anno</span>

### Calcolo rendita — 3 elementi

- <span class="c-def">**Anni contributivi**</span>
  - Rendita piena = <span class="c-dato">44 anni</span> senza lacune
  - <span class="c-warn">1 anno mancante = −2,3% della rendita</span>
  - Recupero possibile entro 5 anni

- **Redditi vita attiva**
  - Sommati e rivalutati per tutta la carriera
  - <span class="c-impl">Compensano i bassi salari di inizio carriera</span>

- <span class="c-def">**Accrediti educativi**</span>
  - Per ogni anno di cura figlio < 16 anni
  - Formula: <span class="c-es">16 × CHF 1'260 × 12 × 3 ÷ 44 = CHF 16'494</span>
  - Se 2 genitori: ÷2 = <span class="c-dato">CHF 8'247</span> ciascuno
  - Reddito **figurativo**, non effettivo

- <span class="c-def">**Accrediti assistenziali**</span>
  - Per cura di familiare con disabilità ≥ grado medio
  - <span class="c-warn">Richiesta scritta **ogni anno**</span>

## AI — Assicurazione Invalidità

- **Regime** → universale
- <span class="c-tesi">**Principio cardine** → integrazione professionale **prima** della rendita</span>
- <span class="c-def">**Invalidità** → definizione economica (non solo medica)</span>
- **Procedura**:
  - Rilevamento tempestivo → entro <span class="c-dato">30 giorni</span>
  - Intervento tempestivo → max <span class="c-dato">12 mesi</span>
    - Adeguamento posto di lavoro, orientamento professionale, collocamento, riabilitazione
  - Decisione → integrazione / rendita / nessun diritto
- **Finanziamento** → contributi su salari + fiscalità generale (IVA); <span class="c-dato">metà delle uscite coperta da risorse pubbliche (¾ Confederazione, ¼ Cantoni)</span>
- **Calcolo rendita AI** → rinviato a Lezione 06

## Prestazioni Complementari (PC)

- <span class="c-def">**Scopo** → integrare AVS/AI quando le risorse non coprono il fabbisogno vitale</span>
- <span class="c-warn">**Condizione** → solo se si ha già una rendita AVS o AI</span>
- **Meccanismo** → <span class="c-def">accertamento dei mezzi (means test)</span>
- **Finanziamento** → fiscalità generale: <span class="c-dato">Confederazione 1/3, Cantoni 2/3</span>

### Patrimonio — regola franchigia
- Franchigia: <span class="c-dato">CHF 30'000</span> (esenti)
- Solo eccedenza entra nel calcolo
- Di essa: solo **1/10** come reddito figurativo

### Restituzione dagli eredi (dal 01.01.2021)
- <span class="c-warn">Se eredità netta > CHF 40'000 → restituzione obbligatoria</span>
- Importo max = eredità netta − CHF 40'000

## Previdenza Professionale (PP) — 2° pilastro

- <span class="c-def">**Obbligatoria**</span> → salariati con salario > <span class="c-dato">CHF 22'680/anno</span> e contratto > 3 mesi
- **Facoltativa** → indipendenti
- <span class="c-def">**Sistema** → capitalizzazione (conto personale + contributo datore di lavoro)</span>
- **Mandato** → <span class="c-dato">art. 113 Cost.</span> → mantenimento tenore di vita
- **Rendita per figli** → <span class="c-dato">+20%</span> della rendita PP · oppure possibile richiedere il **capitale**
- <span class="c-warn">**Disoccupati** → coperti per decesso/invalidità · **nessun accumulo accrediti vecchiaia**</span>
- <span class="c-warn">**Rischi di insufficienza**:</span>
  - Lacune contributive
  - Bassi salari
  - Divorzio (divisione capitale)
  - Prelievo anticipato (casa, indipendente, emigrazione extra-UE)
  - Fluttuazioni mercati

---

## Terzo pilastro

- <span class="c-def">**3a vincolata**</span> → vantaggi fiscali: salariati ~<span class="c-dato">CHF 7'000/anno</span> deducibili; indipendenti fino al 20% del reddito (max <span class="c-dato">CHF 57'800/anno</span>)
- **3b libera** → nessun vincolo, nessun vantaggio fiscale

---

## AINF — Assicurazione contro gli infortuni

- **Obbligo** → salariati (facoltativa per indipendenti)
- <span class="c-warn">**Copertura tempo libero** → solo se ≥ <span class="c-dato">8 ore/settimana</span> presso stesso datore</span>
- **Ente principale** → <span class="c-dato">SUVA</span> (~metà dei salariati)
- **Prestazioni**: preventive · sanitarie · pecuniarie (rendite, indennità giornaliere, AGI, menomazione integrità) · integrative (mezzi ausiliari, riabilitazione)

## Freud: apparato psichico

### Concetti base

- <span class="c-def">**Pulsione** (_Trieb_) → spinta interna dal corpo; non è un istinto; ha fonte / meta / oggetto</span>
- <span class="c-def">**Libido** → energia psichica di natura sessuale che alimenta tutte le funzioni</span>
- **Principio di piacere** → tutto e subito; riduzione immediata della tensione
- <span class="c-tesi">**Principio di realtà** → capacità di differire; valutare; posticipare</span>
  - Residui nell'adulto: sogni, gioco, fantasie

### Prima topica (1900–1915)

| Sistema | Caratteristica |
|---------|---------------|
| <span class="c-def">**Conscio**</span> | Pensiero volontario; principio di realtà |
| **Preconscio** | Non presente ora ma accessibile |
| <span class="c-def">**Inconscio**</span> | Rimosso; lapsus, sogni, sintomi; principio di piacere |

- Metafora: **iceberg** — la parte visibile è solo il conscio
- <span class="c-impl">Conflitto: inconscio (spinge a emergere) vs censura del sistema preconscio-conscio</span>

### Seconda topica (1923–1937)

| Istanza | Funzione | Principio |
|---------|---------|-----------|
| <span class="c-def">**Es**</span> | Pulsioni primitive; biologico; primo a svilupparsi | Piacere |
| <span class="c-def">**Io**</span> | Mediatore; esame di realtà; meccanismi di difesa | Realtà |
| <span class="c-def">**Super-Io**</span> | Coscienza morale; ideali; auto-osservazione | Norma morale |

- **Es** → "un caos, un crogiuolo di eccitamenti ribollenti" (Freud)
- **Io** → metafora del cavaliere che doma il cavallo (ma spesso il cavallo va dove vuole)
- <span class="c-impl">**Super-Io** → nasce dall'identificazione con i genitori (fase edipica); trasmissione intergenerazionale</span>

## Primi tempi della vita

### Prima della nascita

- <span class="c-def">**Concepimento psichico** → atto immaginativo dei genitori; il bambino esiste già nel simbolico</span>
- **Tre bambini in gravidanza**:
  - **Immaginario** → ecografie, sesso, peso; informazioni concrete
  - **Fantasmatico** → proiezioni inconsce; si rivela es. nella scelta del nome
  - **Reale** → chi nascerà davvero; l'incontro può sconvolgere

### Nascita

- <span class="c-def">**Neotenia** → imaturità estrema alla nascita; dipendenza radicale dall'altro</span>
- **Violenza fondamentale** (Aulagnier) → il bambino travolge l'assetto mentale dei genitori con la volontà di vivere

## Competenze del neonato

### Integrazione sensoriale

- <span class="c-tesi">**≥2 canali sensoriali sincronizzati** → costruisce la percezione della realtà esterna</span>
- **Canali distali** → vista, udito (a distanza)
- **Canali prossimali** → tatto, gusto, olfatto (contatto diretto); dominano nei primi mesi

### Stato di vigilanza (arousal)

- **Troppo basso** → non recepisce, non apprende
- <span class="c-tesi">**Zona ottimale** → sveglio, non eccitato; capace di fare esperienza</span>
- **Troppo alto** → disorganizzazione, agitazione
- <span class="c-warn">Condiziona l'efficacia di **tutte** le altre competenze (Holtzman)</span>
- Regolazione **interattiva** → adulto modula (prende in braccio, consola, stimola)
- Regolazione **autonoma** → già rudimentale nel neonato (si gira, si mette il dito in bocca)

## Mentalizzazione

- <span class="c-def">**Definizione** → processo per cui l'adulto dà significato all'esperienza emotiva del bambino</span>
- <span class="c-impl">Il pensiero **contiene e stabilizza** gli stati emotivi</span>
- Doppio binario:
  - Psiche → corpo: pensiero regola emozione
  - Corpo → psiche: yoga, danza, lavoro somatico (van der Kolk — _Il corpo accusa il colpo_)

## Winnicott: funzioni di cura

| Funzione | Descrizione | Effetto |
|----------|-------------|---------|
| <span class="c-def">**Holding**</span> | Come si tiene il bambino | Confini psicosomatici; dentro/fuori |
| <span class="c-def">**Handling**</span> | Come si manipola il corpo (bagno, cambio) | Senso di sé corporeo |
| <span class="c-def">**Object presenting**</span> | La madre media il mondo esterno | Periodo di onnipotenza; base per accettare i limiti |

- **Preoccupazione materna primaria** → identificazione empatica intensa della madre nei primi tempi
- <span class="c-tesi">**Madre abbastanza buona** → risponde sintonizzata ~27% delle volte; sufficiente</span>
- **Accomodamento** → inadempienze crescenti della madre → il bambino impara la realtà esterna
- Tre movimenti relazionali:
  - Differenziarsi senza perdersi di vista
  - Distanziarsi mantenendo la relazione
  - Distaccarsi senza strappi

## Teoria dell'attaccamento (Bowlby / Ainsworth)

### Premesse

- <span class="c-dato">**Bowlby** (1907–1990)</span> → psichiatra britannico; orfani di guerra; consulente OMS
- **Ainsworth** → collaboratrice; ha sviluppato la Strange Situation
- Ispirazione da:
  - **Lorenz** → imprinting nelle paperette
  - <span class="c-es">**Harlow** → scimmie preferiscono madre di pezza morbida (no cibo) a madre metallica (cibo) → attaccamento ≠ nutrizione</span>

### Tesi centrale

- <span class="c-tesi">**Attaccamento** → sistema motivazionale primario; biologicamente determinato</span>
- Importante quanto nutrirsi e riprodursi
- Caratteristiche del legame:
  - Duratura / figura specifica / ricerca sicurezza-conforto / distress alla separazione

### Stili di attaccamento (Strange Situation)

| Stile | Comportamento | Note |
|-------|--------------|------|
| **Sicuro** | Esplora, chiede conforto se stress, si calma facilmente | ~55–65% |
| **Insicuro-evitante** | Continua a giocare, apparentemente indifferente alla separazione | ~20–25% |
| **Insicuro-ansioso** | Molto stressato, difficile da consolare, allerta alta | ~10–15% |
| <span class="c-warn">**Disorganizzato**</span> | Reazioni contraddittorie; fight/flight/freeze; figura = fonte di paura | ~10% |

### Modelli operativi interni

- <span class="c-def">**Definizione** → aspettative inconsce sulle relazioni, formatesi nell'infanzia</span>
- <span class="c-impl">Funzionano come filtri percettivi (occhiali) sulle relazioni future</span>
- Sicuro → fiducia di base; Insicuro → sfiducia, evitamento, ipervigilanza

### Trasmissione intergenerazionale

- **Adult Attachment Interview (AAI)** → valuta qualità narrativa del pensiero sulle proprie esperienze d'infanzia
- Non conta cosa è successo, ma come se ne parla
- <span class="c-tesi">Lo stile dei genitori predice (non determina) quello dei figli</span>

### Mis-match e riparazione

- La sintonizzazione **perfetta non è necessaria**
- <span class="c-tesi">Mis-match + riparazione → fondamentali per la crescita (Stern)</span>

### Note critiche

- <span class="c-warn">La Strange Situation ha **pregiudizi culturali** (valorizza autonomia e indipendenza → visione occidentale)</span>
- **Attaccamento sicuro alternativo** possibile con maestra, nonni, terapeuta → non siamo condannati

## Concetto di sindacato

- <span class="c-def">**Sindacato**</span> → organizzazione stabile di lavoratori salariati per tutelare condizioni lavorative, contrattuali, economiche e sociali
- <span class="c-def">**Contrattazione collettiva**</span> → forma istituzionalizzata del conflitto capitale-lavoro
- <span class="c-def">**Capitale**</span> → datori di lavoro: massimo rendimento al minimo costo
- <span class="c-def">**Lavoro**</span> → dipendenti: salari dignitosi, orari umani, sicurezza
- <span class="c-tesi">**Forza contrattuale**</span> → cresce con l'unione; singolo lavoratore ha poco potere, insieme aumenta

---

## Origini: Rivoluzione Industriale

- <span class="c-def">**Industrializzazione**</span> → <span class="c-dato">Inghilterra, dal 1760 ca.</span>; nascita fabbriche meccanizzate (tessile, metallurgia, ferrovie)
- <span class="c-def">**Proletario**</span> → ex contadino senza terra né mezzi di produzione; la prole è l'unica proprietà
- <span class="c-warn">**Condizioni di lavoro**</span> → fino a 16 ore/giorno; nessuna protezione; lavoro minorile; zero diritti
- <span class="c-def">**Classe operaia**</span> → nuova classe sociale priva di potere, soggetta allo sfruttamento

### Prime risposte

- <span class="c-def">**Società di mutuo soccorso**</span> → casse comuni per malattia/disoccupazione (inizio '800)
- **Scioperi** → rifiuto collettivo di lavorare; blocca produzione, fa pressione sul datore
- <span class="c-dato">**Luddismo (1811-1817)**</span> → <span class="c-es">sabotaggio dei macchinari; Ned Ludd (figura mitica); macchine = causa disoccupazione</span>

### Repressione e legalizzazione

- <span class="c-dato">**Combination Acts (1799-1800)**</span> → formare un sindacato = crimine in Inghilterra
- <span class="c-dato">**Tolpuddle Martyrs (1834)**</span> → <span class="c-es">6 contadini deportati per società di mutuo soccorso → simbolo del diritto di associazione</span>
- <span class="c-dato">**1824-25**</span> → Combination Acts aboliti; nascono i primi **Trade Unions** (unioni di mestiere)
- <span class="c-dato">**1872**</span> → governo inglese legalizza definitivamente i Trade Unions

## Due modelli fondamentali

| | **Sindacato di associazione** | **Sindacato di classe** |
|---|---|---|
| Rappresenta | Solo gli iscritti di un settore | Tutta la classe lavoratrice salariata |
| Obiettivo | Tutele per la categoria specifica | Trasformazioni sociali e politiche |
| Politica | No | Sì |
| Slogan | «Non facciamo politica» | «Uniti per la condizione comune» |
| Origine | Trade Unions inglesi, primo '800 | Legato a movimenti socialisti/socialdemocratici |
| Esempio CH | FSI (impiegati) | USS |

## Sindacalismo in Svizzera

### Tappe storiche

| Anno | Evento |
|---|---|
| <span class="c-dato">1818-1824</span> | Prime società di mutuo soccorso (Aarau, Zurigo, Berna) — artigiani |
| <span class="c-dato">1858</span> | <span class="c-dato">**FST**</span> (Federazione Svizzera dei Tipografi) — primo sindacato strutturato in CH |
| <span class="c-dato">1880</span> | <span class="c-dato">**USS**</span> (Unione Sindacale Svizzera) — coordinamento federale; primo sindacato di classe svizzero |
| <span class="c-dato">1890-1930</span> | Federazioni settoriali: metallurgia, tessile, ferrovie (1894), edilizia; diffusione CCL |
| <span class="c-dato">1907</span> | <span class="c-dato">**FSSC**</span> (Federazione Svizzera dei Sindacati Cristiani) — approccio moderato, valori cattolici-sociali |
| <span class="c-dato">1918</span> | **Sciopero Generale** |
| <span class="c-dato">1937</span> | Primo accordo di pace assoluta (settore meccanico-metallurgico) |
| <span class="c-dato">1956</span> | Pace del lavoro iscritta nel <span class="c-dato">**Codice delle Obbligazioni (art. 357a)**</span> |

### Ostacoli storici

- <span class="c-warn">**Legislazioni cantonali restrittive**</span> → scioperi illegali in molti cantoni
- **Ideologia liberale** → contratto individuale; lo Stato non deve interferire nel mercato del lavoro
- <span class="c-warn">**Repressioni padronali**</span> → licenziamenti, liste nere contro gli attivisti

## Sciopero Generale del 1918

- **Contesto** → <span class="c-es">fine Prima Guerra Mondiale; inflazione alta, disoccupazione, scarsità di viveri; forte divario sociale</span>
- **Organizzatori** → USS + <span class="c-dato">Comitato di Olten</span>
- **Rivendicazioni**:
  - Settimana di <span class="c-dato">**48 ore**</span>
  - <span class="c-dato">**Assicurazione vecchiaia**</span> (futura AVS, 1948)
  - **Parità di trattamento per gli stranieri**
- **Partecipanti** → <span class="c-dato">~250.000 lavoratori</span>; il più grande sciopero svizzero
- <span class="c-warn">**Risposta del CF** → mobilitazione esercito; a Zurigo: **3 morti** (Riggenbach, Nobs, Streuli); feriti in varie città</span>
- **Conseguenze**:
  - <span class="c-tesi">Raffreddamento aspirazioni rivoluzionarie</span>
  - <span class="c-tesi">Svolta verso **negoziazione politica** (strategia riformista)</span>
  - <span class="c-impl">Sindacati diventano interlocutori istituzionali legittimi</span>
  - <span class="c-impl">Avvio del **partenariato sociale** svizzero</span>
  - Sindacati → più burocratizzati, centralizzati, gestione istituzionale

## Pace del Lavoro

- <span class="c-def">**Definizione**</span> → accordo formale per evitare scioperi durante la vigenza di un CCL
- <span class="c-dato">**Art. 357a CO (1956)**</span> → obbligo legale di salvaguardare la pace del lavoro

| Tipo | Regola |
|---|---|
| <span class="c-def">**Pace relativa**</span> | Vietato scioperare solo sui temi **regolati** dal CCL |
| <span class="c-def">**Pace assoluta**</span> | Vietato scioperare su **qualunque** tema, se esplicitamente pattuito |

- **Pro** → stabilità economica; clima favorevole agli investimenti; cooperazione tra le parti
- <span class="c-warn">**Contro** → depotenziamento mobilitazione lavoratori; perdita potere contrattuale; distanza sindacato-base</span>

---

## Sfide attuali

- <span class="c-tesi">**Digitalizzazione**</span> → lavoro frammentato, remoto, algoritmico; CCL difficili da applicare; <span class="c-es">gig economy</span>
- <span class="c-tesi">**Precarizzazione**</span> → contratti temporanei, part-time involontari, carriere discontinue; giovani e donne più esposti
- **Frontalierato** → rischio <span class="c-def">dumping salariale</span>; risposta sindacale: <span class="c-impl">«stesso salario per lo stesso lavoro nello stesso luogo»</span>
- **Sfida strutturale** → <span class="c-tesi">inventare nuove forme di rappresentanza per lavoro frammentato e digitalizzato</span>

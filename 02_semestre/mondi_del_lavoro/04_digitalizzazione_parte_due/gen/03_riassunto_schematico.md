## Concetti base

- <span class="c-def">**Digitale** → traduzione di fenomeni in codice binario (0/1)</span>
- <span class="c-def">**Digitalizzazione del lavoro** → applicazione di algoritmi per organizzare il processo lavorativo</span>
- <span class="c-tesi">**Continuità storica** → già <span class="c-dato">Marx (1800s)</span>: operaio = "organo incosciente di un sistema di macchine"</span>
  - <span class="c-warn">Novità oggi: il meccanismo è uscito dalla fabbrica → pervade ogni spazio, 24h/24</span>

---

## Due narrazioni sull'IA e il lavoro

- <span class="c-def">**Scenario catastrofista** → IA automatizza lavoro fisico E cognitivo → perdita di milioni di posti</span>
- <span class="c-def">**Scenario ottimista** → come nelle rivoluzioni precedenti → nuovi lavori nasceranno</span>
- <span class="c-warn">Entrambe coesistono nel dibattito</span>

---

## Amazon — Caso Studio

- **Obiettivo** → flusso merci continuo, stoccaggio minimo
- <span class="c-es">**Organizzazione magazzino** → apparentemente caotica → algoritmo dispone merci per ridurre errori umani</span>
  - Oggetti diversissimi vicini → più difficile confonderli
- <span class="c-def">**Lavoratori-cyborg** → dispositivi comandano ogni movimento (dove, cosa, in quanto tempo)</span>
- <span class="c-def">**Gamification** → musica, punteggi, gare di velocità</span>
  - <span class="c-dato">Slogan: "Work hard, have fun, make history"</span>
- <span class="c-impl">**Sorveglianza** → telecamere con IA + big data sostituiscono il management</span>

---

## Economia di piattaforma

- <span class="c-def">**Gig economy** → lavoretti a cottimo tramite app (Uber, Deliveroo, Amazon Flex)</span>
- **Differenze dal modello tradizionale**:
  - Niente licenze → accesso aperto
  - Nessun rapporto dipendente → nessuna garanzia
  - Pagamento solo a cottimo → non a ore
- <span class="c-def">**Rating system** → punteggio clienti/driver → determina accesso al lavoro → gamification</span>

### Il rider — meccanismo cottimo

- <span class="c-es">Disponibile 4 ore → pagato solo le consegne effettive</span>
- <span class="c-def">**Lavoro potenziale** (disponibilità) ≠ **lavoro in atto** (consegna pagata)</span>
- <span class="c-impl">Incentivo strutturale alla velocità → competizione automatizzata tra lavoratori</span>

---

## Mito dell'imprenditore di se stesso

- Narrazione piattaforme → "sei libero, i mezzi sono tuoi"
- <span class="c-tesi">Confutazione → il mezzo decisivo è l'**algoritmo**, non la bici/macchina</span>
- <span class="c-impl">Effetto reale → eliminazione tutele + rischi scaricati sul lavoratore</span>

---

## Taylorismo e neo-taylorismo

- <span class="c-def">**Taylorismo** (<span class="c-dato">Frederick Taylor</span>) → divisione scientifica del lavoro in mansioni elementari</span>
- <span class="c-def">**Fordismo** → catena di montaggio → produzione di massa</span>
  - <span class="c-es">Esempio: da 30 a 50 vasi/giorno con le stesse ore</span>
- <span class="c-def">**Neo-taylorismo cognitivo** → stessa logica applicata al lavoro digitale su scala globale</span>
  - Catena di montaggio → catena cognitiva distribuita nel mondo

### Cottimo — ritorno storico

- <span class="c-tesi">Ottocento → sindacati lottano per pagamento a ore (non a pezzo)</span>
- <span class="c-warn">Oggi → piattaforme reintroducono il cottimo mascherato da "flessibilità"</span>

---

## Automazione e ricchezza

- <span class="c-tesi">Automatizzare ≠ negativo di per sé (<span class="c-dato">Christian Marazzi</span>: l'umano delega alle macchine quando può)</span>
- <span class="c-tesi">Problema → **chi incassa la ricchezza prodotta dalle macchine**</span>
- Distribuzione ricchezza:
  - Dopoguerra → **botte** (ceto medio ampio)
  - <span class="c-impl">Oggi → **polarizzazione** (ceto medio svuotato, vertice sempre più ricco)</span>
  - <span class="c-dato">Esempio: Elon Musk → primo umano con 1000 miliardi di dollari</span>

---

## Dati come petrolio digitale

- <span class="c-def">Dati personali → materia prima dell'economia digitale</span>
- <span class="c-es">Modello Instagram → servizio gratuito + raccolta dati → pubblicità mirate + vendita a terzi</span>
- <span class="c-tesi">Paradosso → noi produciamo il valore (dati) ma non siamo retribuiti</span>
- <span class="c-warn">**Rischi** → sorveglianza, controllo politico (<span class="c-dato">Cambridge Analytica</span>)</span>
- <span class="c-es">**Usi positivi** → ricerca medica, vaccino Covid sviluppato in tempi record grazie all'IA</span>

---

## Cosmotecnica — Yuk Hui

- <span class="c-def">Visione occidentale → tecnica = esterna all'umano (separazione uomo/macchina)</span>
- <span class="c-def">Visione cinese → ecologia integrata → umano + tecnica + natura = tutt'uno</span>
- <span class="c-impl">Applicazione → lo smartphone non è uno strumento separato → è già estensione del corpo</span>

---

## Cybersyn e pianificazione dei dati

- <span class="c-dato">**Cybersyn** (Cile, 1971-73)</span> → <span class="c-es">pianificazione economica socialista con dati in tempo reale</span>
  - <span class="c-dato">Interrotto dal golpe del 1973 (sostenuto USA)</span>
- <span class="c-impl">Paradosso (<span class="c-dato">Morozov</span>) → Amazon/Google fanno oggi la stessa cosa, ma per profitto privato</span>

---

## Nuove resistenze

- <span class="c-tesi">Ultimi 10 anni → nuova sindacalizzazione di rider, lavoratori Amazon, piattaforme</span>
- <span class="c-def">**Cyborg working class** → lavoratori innervati di tecnologia → potenziale soggetto politico</span>
- <span class="c-impl">Tecnologie → ambivalenti: strumenti di sfruttamento E potenziale di riappropriazione</span>

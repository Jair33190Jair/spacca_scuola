## Dinamica del cambiamento di sistema

- <span class="c-tesi">**Crisi** → pressione al cambiamento</span>
- **Soluzione** → già esistente a livello micro prima della crisi
- <span class="c-def">**Generalizzazione** → rapida o lenta; spontanea o istituzionalizzata</span>
- <span class="c-warn">**Rendere conto (accountability)** → condizione necessaria perché il cambiamento istituzionale funzioni davvero</span>

---

## Quattro elementi chiave di ogni sistema agricolo

- <span class="c-def">**Fertilità del suolo**</span> → base materiale della produzione
- <span class="c-def">**Sapere**</span> → capacità tecnica di gestione
- <span class="c-def">**Volontà**</span> → motivazione a investire a lungo termine
- <span class="c-def">**Capacità di investire**</span> → risorse economiche disponibili

## Evoluzione storica dei sistemi agrari europei

| Sistema | Produttività | Elementi distintivi |
|---------|-------------|---------------------|
| Romano antico | ~3 qt/ha | Schiavitù, grandi superfici, pluviale, allevamento all'aperto |
| Medievale I rivoluzione | ~6 qt/ha | Stabulazione fissa, mezzadria, nuovi attrezzi |
| Rivoluzione foraggera | ~12 qt/ha | Leguminose azoto-fissatrici (trifoglio) |
| Meccanizzazione | ~24 qt/ha | Varietà migliori, industrializzazione, sovrapproduzione |
| Motorizzazione | >50 qt/ha | Motori, fertilizzanti sintetici, specializzazione, vantaggi comparativi |

## Crisi principali

- <span class="c-es">**Crisi medievale** → sovrappopolazione + esaurimento fertilità → carestie + peste</span>
- <span class="c-es">**Crisi sovrapproduzione XIX sec.** → cereali economici dal Nuovo Mondo → prezzi in crollo → esodo rurale → industrializzazione (solo in Europa)</span>
- <span class="c-es">**Crisi 2008** → petrolio + biocarburanti + speculazione + eliminazione riserve → collasso prezzi alimentari → colpisce i più poveri</span>
  - <span class="c-def">Distinzione: crisi 2022 = crisi di commercializzazione (blocco grano Ucraina), non di sistema produttivo</span>

---

## Lessons learned 2008 — Sicurezza alimentare globale

- <span class="c-tesi">Mercato globale da solo non garantisce sicurezza alimentare</span>
- <span class="c-dato">**>500 milioni**</span> di piccoli agricoltori → cibo per <span class="c-dato">**2 miliardi**</span> di persone
- <span class="c-tesi">Soluzione → piccoli agricoltori locali in grado di investire</span>
- <span class="c-impl">Tendenza attuale → km ridotto, biodiversità, sistemi locali connessi in rete</span>

## Caso ticinese

- <span class="c-def">**Transumanza**</span> → spostamento stagionale bestiame; regolata da patriziati per evitare sovrapascolo
- <span class="c-def">**Patriziati**</span> → custodi di terre collettive; diritto germanico (gestione comune) vs. diritto romano (proprietà privata)
  - A nord di Bellinzona → diritto germanico → gestione collettiva
  - A sud di Bellinzona → diritto romano → masserie private
- **Valverzasca**
  - Dal <span class="c-dato">1600</span> → sistema in crisi latente → emigrazione stagionale
  - <span class="c-dato">1850-1880</span> → <span class="c-es">blocco economico austriaco → disboscamento per carbone → crisi di fertilità → emigrazione di massa (Australia, California)</span>
- **Piano di Magadino**
  - Bonifica <span class="c-dato">~1950</span> → aziende da latte → <span class="c-warn">crisi immediata (non competitive)</span>
  - <span class="c-es">Soluzione → immigrati italiani (Sicilia, Sardegna) → sapere orticolo → conversione a orticoltura</span>

## Analisi di un sistema di produzione agricola

Elementi da osservare:
- **Ecologia** → clima, suolo, terrazzamenti, piante
- **Utensili** → livello di meccanizzazione
- **Capitale umano** → chi lavora, quanti, con quale sapere
- **Produzione** → vegetale/animale; pieno campo / orticola / vitivinicola
- <span class="c-warn">**Fertilità e acqua** → indicatore salute dell'azienda</span>
- **Servizi esterni** → cosa viene acquistato fuori (es. mietitura meccanizzata)

---

## Equazione economica del sistema di produzione

<span class="c-def">**Reddito = A × ettari − B**</span>

- **A** → reddito per ettaro (dipende dal tipo di produzione)
- **B** → costi fissi (investimenti, ammortamenti, debiti)

| Sistema | A (reddito/ha) | B (costi fissi) |
|---------|---------------|-----------------|
| Vite manuale | basso | bassi |
| Caprino manuale | molto basso | bassi |
| Orticoltura | medio-alto | medi |
| Orticoltura biologica | medio | medi |
| Fuori suolo | altissimo | molto alti |

- <span class="c-dato">**Soglia vitale Ticino** → ~36.000 CHF/anno (~3.000/mese)</span>
- <span class="c-warn">Sotto soglia → part-time complementare o sussidi statali</span>

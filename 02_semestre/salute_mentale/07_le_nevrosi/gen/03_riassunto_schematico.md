## Definizione

- <span class="c-def">**Nevrosi**</span> → disturbo psichico senza causa organica
- **Conflitto** → tra desiderio e regola (inconscio); non risolto → sintomo
- <span class="c-tesi">**Non è malattia** → scorretto modo di affrontare la conflittualità interiore</span>

---

## Storia

- <span class="c-dato">**William Cullen**</span> (fine '700) → primo uso del termine; malattie senza substrato organico
- <span class="c-dato">**Philippe Pinel**</span> (1745–1826) → assenza substrato organico; <span class="c-def">trattamento morale</span>
- <span class="c-dato">**Jean-Martin Charcot**</span> (1825–1893) → natura psicologica; ipnosi; Salpêtrière
- <span class="c-dato">**Sigmund Freud**</span> (1856–1939) → dinamica inconscia; Es vs Super-Io; libere associazioni
- **DSM-III in poi** → termine abbandonato; frammentazione in diagnosi specifiche

---

## Nevrosi nel DSM-5-TR (dove sono finite)

- Disturbi d'ansia → disturbo d'ansia generalizzato, fobia specifica, panico, agorafobia...
- DOC e disturbi correlati → DOC, dismorfismo corporeo, disturbo da accumulo, tricotillomania...
- Disturbi traumatici → PTSD, disturbo da stress acuto
- Disturbi somatici → disturbo da sintomi somatici, disturbo da ansia di malattia

---

## Patologia vs. normalità — 3 criteri

- <span class="c-def">**Durata**</span> → sintomi persistenti nel tempo (es. ≥ 6 mesi)
- <span class="c-def">**Intensità**</span> → frequenza elevata, non sporadica
- <span class="c-def">**Compromissione**</span> → impatto su lavoro, relazioni, vita quotidiana

---

## Sintomo egodistonico vs. egosintonico

| | <span class="c-def">**Egodistonico**</span> (nevrosi) | **Egosintonico** (disturbi personalità) |
|---|---|---|
| Consapevolezza | Sì, sa che è irrazionale | No, lo vive come parte di sé |
| Sofferenza | Elevata | Ridotta o assente |
| Richiesta di aiuto | <span class="c-impl">Più facile</span> | Difficile; spesso via terzi |

---

## Fenomenologia del disturbo nevrotico

- **Esperienza del sé** → bassa autostima, indecisione, colpa, vergogna, <span class="c-def">demoralizzazione</span>
- **Umore** → ansia (dominante), depressione, irritabilità; disturbi del sonno
- **Somatici** → disturbi motori, ipocondria, dolori somatoformi, dismorfofobia
- **Relazioni** → compromesse in tutte le aree (lavoro, famiglia, coppia, sociale)
- <span class="c-tesi">**Esame di realtà** → mantenuto (≠ psicosi)</span>

---

## Struttura nevrotica (<span class="c-dato">Bergeret</span>)

- <span class="c-def">**Struttura**</span> → organizzazione permanente profonda della personalità; <span class="c-warn">non è patologia</span>
- <span class="c-def">**Scompenso**</span> → rottura dell'equilibrio → patologia
- <span class="c-warn">**Diagnosi di struttura** → solo in età adulta (~20–25 anni)</span>
- <span class="c-warn">**Sintomi trasversali** → non diagnosticare solo dai sintomi</span>

### Caratteristiche struttura nevrotica

- **Istanza dominante** → Super-Io
- **Conflitto** → edipico (Super-Io vs Es)
- <span class="c-def">**Angoscia**</span> → di castrazione
- **Relazione oggettuale** → genitale (altro come individuo reale)
- <span class="c-def">**Difesa principale**</span> → rimozione

### Linea di divisione (<span class="c-dato">Karl Abraham</span>)

- Strutture psicotiche ← sotto-stadio anale evacuazione (2–3 anni)
- **DIVIDED LINE**
- Strutture nevrotiche ← sotto-stadio anale ritenzione (3–4 anni)

## DOC — Disturbo Ossessivo-Compulsivo

- <span class="c-tesi">**Luogo del sintomo** → il pensiero</span>

### Ossessioni

- <span class="c-def">**Definizione**</span> → pensieri/immagini/impulsi non voluti, incontrollabili, incongruenti con i valori
- **Categorie** → <span class="c-es">contagio · responsabilità del danno · simmetria/ordine · sessuali · violenza · religione</span>
- **3 caratteristiche cliniche** →
  - non desiderate e incontrollabili
  - incongruenti con il sistema di valori
  - la persona tenta di resistere

### Compulsioni

- <span class="c-def">**Definizione**</span> → rituali comportamentali o mentali per ridurre l'ansia ossessiva
- <span class="c-tesi">**Non agite per piacere** → danno **sollievo** (≠ piacere)</span>
- **Categorie** → <span class="c-es">decontaminazione · controllo · ripetizione · rituali mentali</span>
- **DSM-5-TR** → > 1 ora/giorno o compromissione funzionamento
- <span class="c-impl">**Evitamento** → persone/luoghi/situazioni che innescano ossessioni</span>

### Meccanismi di difesa nel DOC (secondari)

- <span class="c-def">**Rimozione**</span> → impulsi inaccettabili eliminati dalla coscienza → ritornano come ossessioni
- <span class="c-def">**Formazione reattiva**</span> → affetto negativo trasformato nel polo opposto
- <span class="c-def">**Spostamento**</span> → ansia diretta verso oggetto/rituale meno minaccioso
- <span class="c-def">**Isolamento**</span> → componente affettiva separata da quella cognitiva
- <span class="c-def">**Annullamento retroattivo**</span> → comportamento che cancella simbolicamente pensieri/azioni precedenti

## Nevrosi isterica

- <span class="c-tesi">**Luogo del sintomo** → il corpo</span>

### Storia

- Greco: *hystéra* = utero
- <span class="c-dato">Ippocrate</span> (V a.C.) → prime descrizioni; bolo esofageo, difficoltà respiratorie
- <span class="c-dato">Charcot</span> → 4 fasi crisi: <span class="c-es">epiletoide → contorsioni (posizione ad arco) → allucinatoria → delirio</span>
- <span class="c-dato">Freud</span> → libere associazioni; trauma reale → poi trauma immaginario

### Conversione

- <span class="c-def">**Conversione**</span> → conflitto psichico irrisolto trasferito sul piano somatico
- Sintomo = compromesso tra pulsione e paura dell'emergenza

### Struttura isterica (<span class="c-dato">Bergeret</span>)

- Caratteristica → forza della componente erotica
- Difesa principale → rimozione
- <span class="c-def">**Isterica di conversione**</span> → sintomi fisici (<span class="c-es">paralisi, anestesie, disturbi motori</span>)
- <span class="c-def">**Isterica d'angoscia**</span> → fobia (ansia su oggetto simbolico esterno); meccanismo = spostamento

### Oggi nel DSM-5-TR

- Disturbi dissociativi → disturbo dissociativo identità, amnesia dissociativa
- Disturbi somatici → disturbo da sintomi somatici, disturbo da ansia di malattia, disturbo da sintomi neurologici funzionali
- Disturbi d'ansia → <span class="c-def">**fobia specifica**</span> (ansia marcata, sproporzionata, verso oggetto/situazione precisa)

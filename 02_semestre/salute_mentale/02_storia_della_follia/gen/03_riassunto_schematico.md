## I due paradigmi

- <span class="c-def">**Gehirnpsychiatrie** → follia = malattia organica del cervello</span>
  - Esempio: <span class="c-es">Donizetti (sifilide → paralisi progressiva)</span>
- <span class="c-def">**Geistespsychiatrie** → follia = prodotto di passioni / traumi / vita</span>
  - Esempio: <span class="c-es">Lucia di Lammermoor (violenza, inganno → dissociazione)</span>
- **Comprensibilità** (Jaspers):
  - <span class="c-impl">Follia passionale → comprensibile (ci ritroviamo qualcosa)</span>
  - <span class="c-impl">Follia organica → incomprensibile</span>
- <span class="c-def">**Alienazione** → essere "altrove", fuori dal proprio mondo</span>

---

## Evoluzione storica

- **Grecia arcaica** → <span class="c-tesi">follia = punizione / possessione divina</span>
- <span class="c-dato">**Asclepio / Asclepidi** (V sec. a.C.)</span> → "ordine dei medici" del mondo antico
- <span class="c-dato">**Ippocrate** (~460 a.C.)</span> → <span class="c-tesi">emancipazione dalla religione</span>
  - <span class="c-def">**Teoria degli umori**: squilibrio = malattia</span>
    - Bile nera / terra → melanconico
    - Sangue / aria → sanguigno
    - Flegma / acqua → flemmatico
    - Bile gialla / fuoco → collerico
  - "Squilibrato" nel linguaggio comune → da qui
  - I **fluidisti** → seguaci per secoli
- **Empedocle** → <span class="c-def">equilibrio tra poli contrari (caldo/freddo, umido/secco)</span>
- **Medioevo** → <span class="c-warn">religione domina; nessuna novità medica originale</span>
- **1500–1600** → rinascita delle scienze
  - <span class="c-dato">Mercuriale (1530–1606)</span> → catatonia
  - <span class="c-dato">Weyer (1515–1588)</span> → <span class="c-es">allucinazioni visive; streghe e erbe psicoattive</span>
- **1600–1700** → "Homme Machine" → <span class="c-def">uomo come organismo meccanico</span>
  - <span class="c-dato">De Lamettrie (1747)</span> → _L'uomo macchina_
  - <span class="c-dato">Cullen (1777)</span> → conia <span class="c-def">**nevrosi**</span>
  - <span class="c-es">Beard (XIX sec.) → **nevrastenia** (cervello come batteria scaricabile)</span>

---

## Pinel — fine XVIII sec.

- <span class="c-es">Bicêtre 1793 → libera i folli dalle catene</span>
- <span class="c-tesi">Tesi: follia da passioni ≠ malattia del cervello → **guaribile**</span>
- Quattro principi:
  - <span class="c-def">**Guaribilità** → follia da passioni si cura</span>
  - <span class="c-def">**Patoplastica** → malattia si esprime in modo unico su ogni persona</span>
  - <span class="c-def">**Parzialità della follia** → rimane sempre una parte sana</span>
    - <span class="c-impl">Non attaccare il delirio → rivolgersi alla parte sana</span>
  - <span class="c-def">**Trattamento morale** → cura via relazione e ascolto</span>
- <span class="c-tesi">Conoscenza della storia del paziente → precondizione della cura</span>
- <span class="c-dato">**Esquirol** (allievo, 1772–1840)</span>:
  - Follia passionale → curabile
  - Follia organica → incurabile
  - <span class="c-def">Idiozia = condizione di nascita</span>
  - <span class="c-def">Demenza = deterioramento acquisito</span>

---

## Positivismo — XIX sec.

- <span class="c-dato">**Griesinger** (1817–1868)</span> → <span class="c-tesi">"follia = malattia del cervello"</span>
  - **Somatiker** (organicisti) vs. **Psychiker** (psicologisti)
- <span class="c-es">**Moleschott** → "pensiero : cervello = urina : reni"</span>
- <span class="c-dato">**Morel** (1809–1873)</span> → <span class="c-def">teoria della **degenerazione**</span>
  - <span class="c-impl">Follia = involuzione evolutiva (sull'onda di Darwin, 1859)</span>
  - Progressiva e irreversibile
  - Inizia con il **delirio paranoico**:
    - _Parà_ (di fianco) + _noos_ (pensiero) → pensiero parallelo alla realtà
    - <span class="c-def">Premessa non universale + autoriferimento → deduzione falsa ma internamente coerente</span>
  - Porta alla **demenza precoce**
- <span class="c-dato">**Lombroso** (1835–1909)</span> → <span class="c-es">antropologia criminale — misurazioni, **atavismo**, "tristissimo Villella"</span>

---

## Kraepelin — nosologia

- <span class="c-warn">Sintomi = segni da classificare (non da ascoltare)</span>
- **Malattie esogene** (cause esterne):
  - Psicologiche → traumi (cicatrice cerebrale)
  - Somatiche → infezioni, pellagra, batteri

| Malattia endogena | Asse compromesso | Decorso |
|-------------------|-----------------|---------|
| **Psicosi maniaco-depressiva** | Emotivo | Parzialmente reversibile |
| **Demenza precoce** | Unità interna | Progressiva, irreversibile |

- <span class="c-def">**Psicosi maniaco-depressiva**</span>:
  - Maniacale → attenzione dispersa, percezione superficiale, ideazione accelerata, ipermotilità
  - Depressiva → attenzione difficile, percezione chiusa, ideazione povera, rallentamento / immobilità
- **Demenza precoce** → <span class="c-tesi">salta la coerenza interna</span>: attenzione spenta, allucinazioni, pensiero disordinato, emozioni spente, abulia / impulsività

---

## Bleuler — Schizofrenia (1911)

- <span class="c-dato">Bleuler</span> rinomina demenza precoce → <span class="c-def">**schizofrenia**</span>
- <span class="c-def">**Sintomi primari** (fondamentali) → organici, subiti passivamente</span>
- <span class="c-def">**Sintomi secondari** (accessori) → reazione psicologica soggettiva; variabili da persona a persona</span>
- <span class="c-impl">Recupera principio patoplastico di Pinel</span>

---

## La Pellagra

- <span class="c-def">**3 D** → Dermatosi · Diarrea · Demenza (+ Death)</span>
- <span class="c-tesi">Causa → **monofagismo maidico** (dieta di mais → carenza di vitamina B3 / niacina)</span>
- <span class="c-impl">Malattia della povertà → malati internati in manicomio</span>
- <span class="c-es">Caso emblematico: Mattio Lovat (1814)</span>

---

## Dimensione identitaria della follia

- Malattia mentale mette in crisi:
  - <span class="c-def">**Identità** (chi sono?)</span>
  - <span class="c-def">**Spazialità** (dove sono? → "altrove")</span>
  - <span class="c-def">**Temporalità** (in che tempo vivo?)</span>
- <span class="c-es">Vocabolario popolare: tutto spaziale ("fuori di testa", "spostato", "fuori come un balcone")</span>
- <span class="c-tesi">**Avere** la malattia ≠ **essere** la malattia</span>
  - _Avere_ → non identificazione
  - _Essere_ → <span class="c-warn">identificazione identitaria → paradigma di cura diverso</span>

---

## Cargnello

- <span class="c-tesi">Ambiguità irriducibile della psichiatria: **"Essere con qualcuno"** vs. **"avere qualcosa di fronte"**</span>
- <span class="c-impl">La clinica = incontro tra umani, non classificazione di oggetti</span>

## Semiologia — Concetti base

- <span class="c-def">**Segni**</span> → indicatori oggettivi rilevabili dal curante
- <span class="c-def">**Sintomi**</span> → indicatori soggettivi riferiti dal paziente
- **2 aree**: semiologia del comportamento · semiologia dello stato mentale attuale

---

## Semiologia del Comportamento

- **Apparenza**
  - <span class="c-def">Ipertimia</span> → mimica espressiva (<span class="c-es">fasi maniacali</span>)
  - <span class="c-def">Amimia</span> → mimica assente (<span class="c-es">depressione, Parkinson</span>)
  - <span class="c-def">Mimica discordante</span> → espressione ≠ emozione vissuta (<span class="c-es">schizofrenia</span>)
- **Discorso** → velocità, tono, fluenza, bisogno di stimolazione
- **Condotte istintuali**
  - Cura del sé: igiene, alimentazione, sonno, relazioni
  - Disturbi del sonno: <span class="c-es">risvegli precoci (umore) · insonnia iniziale (ansia)</span>
  - Disturbi sessuali e alimentari: temi delicati, spesso legati a effetti collaterali
  - Disturbi sfinterici: <span class="c-es">nelle demenze (incontinenza urinaria → fecale)</span>
- **Passaggi all'atto**
  - Auto-aggressivi · etero-aggressivi
  - <span class="c-def">Fuga dissociativa</span> → allontanamento post-trauma, amnesia episodio (<span class="c-warn">≠ allontanamento nelle demenze</span>)
  - Disturbi impulsi: <span class="c-es">piromania · cleptomania</span>
- **Funzioni psicomotorie**
  - Agitazione psicomotoria
  - <span class="c-def">Catatonia</span> → perdita iniziativa motoria + ipertono muscolare
  - <span class="c-def">Tic</span> → movimenti rapidi involontari al volto
  - <span class="c-def">Paracinesi</span> → movimenti alterati fuori contesto
  - <span class="c-def">Stereotipie</span> → sequenze comportamentali ripetute

## Semiologia dello Stato Mentale Attuale

### Coscienza

- <span class="c-def">**Cosciente**</span> = sa chi è + sa dove è + reagisce all'ambiente
- Asse vigilanza · asse lucidità · asse coscienza di sé
- Alterazioni **quantitative**: lucidità → ottundimento → torpore → sopore → coma
- Alterazioni **qualitative**:
  - Stato confusionale/delirium
  - <span class="c-def">Mania à potu</span> → mania da bassi quantitativi di alcol (<span class="c-warn">≠ delirium tremens = astinenza</span>)
  - Stato crepuscolare → epilessia, psicosi
  - Stato oniroide → tipo sogno, possibili allucinazioni visive
  - Automatismo → gesti abituali fuori contesto
  - Stupore → legato alla catatonia
  - Fenomeni dissociativi

### Orientamento (3 domini)

| Dominio | Labilità | Rilevanza clinica |
|---|---|---|
| Tempo | Alta (anche senza patologia) | Bassa se isolato |
| Spazio | Media | Significativa |
| Persona (so chi sono) | Bassa | Massima gravità |

> <span class="c-warn">Spazio + tempo alterati → sospetto problematica cerebrale</span>

### Memoria

| Tipo | Durata | Note |
|---|---|---|
| Sensoriale | 1-2 sec | Iconica (visiva) · Ecoica (uditiva) |
| Breve termine | ~20-30 sec | 5-9 elementi · capacità limitata |
| Di lavoro | Variabile | Rielabora le info → funzioni esecutive |
| Lungo termine | Illimitata | Implicita + Esplicita |

- **MLT implicita** → automatismi (guidare, lavarsi i denti)
- **MLT esplicita episodica** → eventi della vita
- **MLT esplicita semantica** → nozioni apprese

**Disturbi quantitativi:**
- <span class="c-def">**Ipomnesia**</span> → traccia ridotta
- <span class="c-def">**Amnesia anterograda**</span> → no codifica nuove info dopo evento indice
- <span class="c-def">**Amnesia retrograda**</span> → no recupero info prima dell'evento indice
- **Ipermnesia** → capacità aumentata

**Disturbi qualitativi (paramnesie):**
- **Falsi ricordi** → rievocazione involontariamente distorta
- <span class="c-def">**Confabulazioni**</span> → falsificazioni involontarie in stato lucido (<span class="c-es">es. <span class="c-dato">Korsakoff</span></span>)
- **Déjà vu/vécu** → sensazione di familiarità, <span class="c-warn">non necessariamente patologica</span>

### Attenzione

- <span class="c-def">**Selettiva**</span> → focus su un obiettivo, esclude il resto
- <span class="c-def">**Divisa**</span> → più fonti contemporaneamente (solo con schemi cognitivi diversi)
- <span class="c-def">**Sostenuta**</span> → attenzione a lungo su compiti monotoni; <span class="c-impl">sensibile all'invecchiamento</span>

### Percezione

- <span class="c-def">**Sensazione**</span> → dato grezzo dai sensi
- <span class="c-def">**Percezione**</span> → rielaborazione soggettiva del cervello basata sull'esperienza

**Distorsioni quantitative:**
- Iperestesia → amplificazione
- Ipoestesia → riduzione

**Distorsioni qualitative:**
- Micropsia / Macropsia / Dismegalopsia
- Dissociazione delle percezioni

**False percezioni:**
- <span class="c-def">**Illusione**</span> → stimolo reale + interpretazione erronea (affettiva, da completamento) — <span class="c-warn">non patologica di per sé</span>
- <span class="c-def">**Allucinazione**</span> → nessuno stimolo reale · percezione vissuta come reale

**Agnosie** → sensi integri, ma incapacità di riconoscere:
- Visiva / Uditiva / Tattile / Gustativa
- <span class="c-def">**Prosopagnosia**</span> → incapacità di riconoscere volti
- <span class="c-def">**Anosognosia**</span> → incapacità di riconoscere il proprio stato di malattia

## Funzioni Cognitive

- **Memoria** · **Attenzione** · **Funzioni esecutive** (problem solving, pianificazione, inibizione)
- **Linguaggio** · **Prassie** (movimenti pianificati) · **Funzioni gnosico-percettive** · **Emozioni**
- <span class="c-tesi">Neurotrasmettitori principali: <span class="c-dato">dopamina · serotonina · noradrenalina · GABA · glutammato · acetilcolina</span></span>

## Psicofarmacologia

- <span class="c-def">**Emivita**</span> → tempo per ridurre del 50% il farmaco nel sangue → <span class="c-impl">determina intervalli di somministrazione</span>
- <span class="c-def">**Farmacodinamica**</span> → meccanismo d'azione
- <span class="c-def">**Farmacocinetica**</span> → assorbimento, distribuzione, eliminazione

### Classi principali

| Classe | Bersaglio | Note chiave |
|---|---|---|
| **Antipsicotici** | Sintomi positivi (deliri, allucinazioni) | Tipici (<span class="c-dato">1952</span>) = più effetti coll. · Atipici (anni '90) = meno |
| **Antidepressivi** | Depressione + ansia + OCD + altro | Bifasici: effetto dopo 2-3 sett. · <span class="c-warn">rischio suicidale nelle prime sett.</span> |
| **Ansiolitici** | Ansia acuta | Benzodiazepine: effetto immediato, <span class="c-warn">dipendenza a lungo termine</span> |
| **Stabilizzatori** | Disturbo bipolare | <span class="c-dato">Litio</span>: tossico se sovradosato · monitoraggio ematico necessario |

⚠️ <span class="c-warn">Non dedurre la diagnosi dalla terapia farmacologica</span>
⚠️ <span class="c-tesi">La terapia è sempre integrata — il farmaco è una parte, non la soluzione</span>

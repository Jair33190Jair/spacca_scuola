## Séguin e la svolta pedagogica

- **Contesto** → <span class="c-tesi">idiozia = stato permanente e ineducabile</span> (Esquirol)
- **Séguin** → allievo di Itard; 25 anni; <span class="c-dato">1839</span>: apre prima scuola per idioti
- **Metodo** → programma <span class="c-def">fisico + intellettuale + morale</span>
- **Opere** → <span class="c-dato">"Igiene e educazione degli idioti" (1843)</span> · <span class="c-dato">"Trattamento morale degli idioti" (1846)</span>
- **Emigrazione** → <span class="c-dato">1851</span>: USA; classi a Boston; fonda <span class="c-dato">AAMD</span>

---

## Darwin e il darwinismo sociale

- **1859** → <span class="c-dato">"L'origine della specie"</span>
- **Tesi biologica** → selezione naturale
- **Tesi sociale** → frenare la riproduzione degli "esseri deboli"
- <span class="c-warn">Darwin non crea l'eugenismo — fornisce la legittimazione scientifica mal usata</span>

---

## Eugenismo

- **Termine** → <span class="c-dato">1880</span>, coniato da <span class="c-dato">Francis Galton</span> (cugino di Darwin)
- **Definizione** → <span class="c-def">scienza del miglioramento della discendenza per favorire le "razze più dotate"</span>
- **Logica** → talento ereditario → élite inglese → parenti eminenti
- **"Razza"** → concetto vago: bianchi, inglesi, **ma anche poveri**
- <span class="c-impl">Povertà = deficit genetico, non condizione economica</span>
- **Degenerescenza** → <span class="c-def">deficit intellettivo + povertà + criminalità = inferiorità biologica unica</span>
- **Periodo dominante** → <span class="c-dato">1885–1925</span>

---

## Eugenismo applicato

| Misura | Dettaglio |
|--------|-----------|
| <span class="c-def">Segregazione</span> | Istituti enormi, isolati, "doppia funzione" |
| <span class="c-def">Sterilizzazione</span> | Volontaria → poi obbligatoria dal <span class="c-dato">1920</span> |
| <span class="c-def">Controllo immigrazione</span> | Blocco delle "razze inferiori" |

- **Istituti** → gigantismo · numerosi · ideologia di contenimento
- **Doppia funzione** → proteggere i "normali" / proteggere gli "anormali"
- <span class="c-es">Es: Istituto Cottolengo, Torino</span>
- <span class="c-warn">Fino agli anni '60: nessuna voce critica contro questi istituti</span>

---

## Nazismo e sterminio

- **Nome nazista** → <span class="c-def">"igiene razziale"</span>
- **1920** → <span class="c-dato">Binding + Hoche</span>: nozione di <span class="c-def">"esseri inutili"</span> ("idioti incurabili")
- **Principio** → <span class="c-tesi">la persona deve giustificare il fatto di essere in vita</span>
- **Progressione misure naziste:**
  - Cause biologiche: <span class="c-def">triade infernale</span> (deficit intellettivo + povertà + deficienza morale)
  - Poi: vagabondi, disoccupati, omosessuali, delinquenti
- **1939** → decreto di <span class="c-dato">Hitler</span>: <span class="c-def">"programma eutanasia"</span> (nome in codice: Aktion T4)

---

## Dopoguerra e ricostruzione

- <span class="c-warn">Le idee eugeniste non spariscono con il nazismo</span>
- **Fino agli anni '70** → istituzionalizzazione ancora misura dominante (USA + Europa)
- **Condizioni** → generalmente disastrose
- **Agenti del cambiamento** → <span class="c-tesi">associazioni di genitori di bambini con disabilità</span>
- <span class="c-impl">Il cambiamento arriva dal basso, non dai governi</span>
- **Nuove strutture** → internato + esternato · educazione sociale · terapie

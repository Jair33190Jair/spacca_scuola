## Definizione (AAIDD 2022)

- <span class="c-def">**Deficit Intellettivo (DI)**</span> → limitazioni significative in:
  - Funzionamento intellettivo
  - Comportamento adattivo
  - Con origine prima dei <span class="c-dato">22 anni</span>

---

## 3 Criteri Diagnostici

- **A. Funzionamento intellettivo** → <span class="c-dato">QI < 70</span> (≥ 2 DS sotto la media)
- **B. Comportamento adattivo** → ≥ 2 DS sotto la media in almeno 1 dei 3 domini
- **C. Età di esordio** → prima dei 22 anni
- <span class="c-warn">⚠️ Tutti e tre devono coesistere — manca uno, niente diagnosi</span>

---

## A. Funzionamento Intellettivo

- **Comprende** → pensiero, apprendimento, ragionamento, pianificazione, imparare dall'esperienza
- **Misurato con** → test QI standardizzati (Wechsler, Stanford-Binet)
- **Media** → 100 · **DS** → 15 · <span class="c-def">**Soglia DI** → QI < 70</span>
- **Curva di Gauss** → sotto 70 = <span class="c-dato">2,3%</span> della pop. · diagnosi DI = <span class="c-dato">1–1,5%</span> (perché serve anche criterio B)

### Storia del QI

| Chi | Cosa | Quando |
|-----|------|--------|
| <span class="c-dato">Binet + Simon</span> | Prima Scala metrica dell'intelligenza (30 prove) | <span class="c-dato">1905</span> |
| Binet | Padre della <span class="c-def">psicometria</span> | 1905 |
| <span class="c-dato">Stern</span> | Introduce il termine "Quoziente Intellettivo" (EM/EC × 100) | dopo Binet |
| Stanford | Revisione: Scala Stanford-Binet (QI moderno) | revisioni successive |

- **Formula classica** → QI = (Età Mentale / Età Cronologica) × 100
- <span class="c-warn">⚠️ Limiti QI → dato cifrato dice poco; serve profilo funzionale completo; somministrare in lingua madre</span>

---

## B. Comportamento Adattivo

- <span class="c-def">**Definizione** → insieme di abilità concettuali, sociali e pratiche per il funzionamento quotidiano</span>
- **Caratteristiche** → evolutivo · dipende dal contesto · valutato su prestazione tipica (non migliore)

### Tre domini

| Dominio | Esempi di limitazioni |
|---------|-----------------------|
| **Concettuale** | Pianificazione, pensiero astratto, simboli (tempo/denaro), lettura/scrittura/aritmetica |
| **Sociale** | Giudizio sociale, suggestionabilità, credulità, rischio vittimizzazione, compiacere l'autorità |
| **Pratico** | Cura di sé, gestione casa, lavoro, uso denaro, sicurezza ambiente |

---

## C. Età di Esordio

- **Limite** → <span class="c-dato">22 anni</span> (arbitrario; prima era 18 poi 20)
- **Scopo** → <span class="c-impl">esclude la demenza (perdita capacità in età adulta)</span>
- **Quando** → per lo più diagnosi in prima infanzia

---

## Terminologia

- <span class="c-def">**Deficit intellettivo**</span> → termine corretto oggi
- <span class="c-warn">**"Ritardo mentale"** → obsoleto, da non usare</span>
- <span class="c-def">**Disabilità cognitiva**</span> → termine più ampio (cappello)
  - Include DI + disturbi apprendimento + ADHD + difficoltà percettive sensoriali
  - <span class="c-warn">⚠️ Non tutte le disabilità cognitive sono DI</span>

---

## Classificazione per intensità

| Livello | QI | Sostegni |
|---------|----|----------|
| Gravissimo | 0–20/25 | Continuo |
| Grave | 20/25–40/45 | Estensivo |
| Medio/medio-grave | 40/45–55 | Limitato |
| Leggero/lieve | 55–70/75 | Intermittente |

- <span class="c-tesi">⚠️ Classificazione per QI imprecisa nella pratica → meglio classificare per intensità bisogno di sostegno</span>

---

## Prevalenza

- <span class="c-dato">**1–1,5%**</span> popolazione generale (DSM-5)
- Variabile per paese (dipende da cause, medicina, alimentazione)

---

## Eziologie

| Causa | % |
|-------|---|
| Alterazioni sviluppo embrionale | <span class="c-dato">30%</span> |
| Gravidanza + periodo perinatale | <span class="c-dato">10%</span> |
| Ereditaria | <span class="c-dato">5%</span> |
| Condizioni mediche infanzia | <span class="c-dato">5%</span> |
| Ambientali + altri disturbi mentali | <span class="c-dato">15–20%</span> |
| **Sconosciuta** | <span class="c-warn">**30–40%**</span> |

### Fattori di rischio per periodo

- **Prenatale** → anomalie cromosomiche, malnutrizione materna, <span class="c-warn">alcol (anche piccole dosi → <span class="c-def">Sindrome Alcolica Fetale</span>)</span>, droghe, violenza domestica
- **Perinatale** → <span class="c-es">prematurità, ipossia al parto</span>
- **Postnatale** → <span class="c-es">traumi cerebrali, deprivazione sociale, mancanza stimolazione, povertà</span>

---

## Sistemi di Sostegno

- <span class="c-tesi">**Scopo della diagnosi** → sviluppare profilo dei sostegni necessari</span>
- **Effetto dei sostegni** → migliorano il funzionamento · <span class="c-warn">non eliminano la disabilità</span>

### 4 caratteristiche dei sistemi efficaci (AAIDD 2022)

- **Centrati sulla persona** → bisogni + desideri al centro
- **Completi** → coprono tutti i contesti di vita
- **Coordinati** → qualcuno gestisce la rete (genitori, operatori)
- **Orientati agli esiti** → <span class="c-impl">impatto misurabile</span>

### Tipologie di sostegno

- **Naturali/generici** → famiglia, amici, comunità, tecnologia assistiva, ambienti inclusivi
- **Specialistici** → operatori sociali, terapisti, didattica speciale, sensibilizzazione pubblica

### Concetti correlati

- <span class="c-def">**Scaffolding**</span> (<span class="c-dato">Wood, Bruner, Ross 1976</span>) → sostegno come impalcatura; orienta senza sostituirsi; si toglie con la crescita
- <span class="c-def">**ZSP di Vygotskij**</span> → calibrare i sostegni vicino ai bisogni attuali; aggiornare con l'evoluzione della persona
- <span class="c-def">**SIS**</span> (<span class="c-dato">Thompson et al., 2004</span>) → Supports Intensity Scale; misura entità dei sostegni necessari; standardizzazione italiana: <span class="c-dato">Cottini et al., 2008</span>

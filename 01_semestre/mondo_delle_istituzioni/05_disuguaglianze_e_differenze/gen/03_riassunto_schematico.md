# Disuguaglianze e differenze — Schema
Il mondo delle istituzioni · Sessione 05

## Rappresentare la società

- **Rappresentazioni** → stratificazione, reti, piramide/gerarchia
- **Teoria** → semplificazione per spiegare funzionamento e cambiamento
- **Attrezzi del corso** → istituzionalizzazione → socializzazione → Bourdieu

## Costruttivismo strutturale genetico

- **Sintesi di due prospettive**
  - **Positivista** → fatti come cose (Durkheim), conoscenza esteriore
  - **Soggettivistica** → conoscenza pratica, dall'interno
- **Costruttivismo** → realtà costruita dall'agire delle persone
- **Strutturale** → regole formali oggettive
- **Genetico** → genesi e storia: strutture storicamente situate e modificabili
- **Pratiche** → gesti, parole, comportamenti = esternalizzazione
- <span class="c-tesi">**Il reale è relazionale**</span> → strutture ↔ schemi individuali (dialettica)

## Habitus

- <span class="c-def">**Habitus** → società iscritta nel corpo; schemi incorporati di percezione, pensiero, azione</span>
  - pilota automatico
  - esempi: gusti, accento, studio, fiducia nelle istituzioni
- **Riproduzione** → habitus trasmesso tra generazioni
  - → resistenza al cambiamento
  - → <span class="c-warn">chi nasce povero tende a restarlo (anche in Svizzera)</span>

## Campo

- <span class="c-def">**Campo** → microcosmo con fine specifico, regole e autorità proprie, autonomia relativa</span>
  - es.: religioso, politico, economico, giuridico, scolastico, burocratico
  - metafora: campo da calcio
- **Campo di forze + campo di battaglia** → competizione per il capitale
- <span class="c-warn">Non stabile né immutabile</span>

## Capitale

- <span class="c-def">**Capitale** → risorsa vantaggiosa: accumulabile, trasmissibile, convertibile</span>
- **Capitale ↔ potere** → circolarità

| Forma | Contenuto | Esempio |
|---|---|---|
| **Economico** | denaro, beni | lezioni private per figli benestanti |
| **Culturale** | sapere, titoli | laurea → carriera |
| **Sociale** | reti | migrante con rete trova casa e lavoro |
| **Simbolico** | prestigio | giudice, professore affermato |

- **Mix per campo** → accademia: culturale · volontariato: gratuità · politica: economico (opinione della docente)
- **Conversione** → solo se il capitale è riconosciuto nel contesto

## Spazio sociale

- **Asse verticale** → volume di capitale
- **Asse orizzontale** → composizione (culturale ↔ economico)
- **In alto** → campo del potere
- <span class="c-warn">Si collocano gruppi, non individui</span>

## Disuguaglianze

- **Società** → competizione, non armonia
- **Regole del gioco** → definite da qualcuno → <span class="c-impl">modificabili</span>
- **Film** → immigrati: economico basso, culturale non riconosciuto, sociale alto (compensazione)
- **Analisi fine** → sottogruppi con interessi diversi

## Ripasso socializzazione secondaria

- **Al lavoro** → si impara osservando e imitando
- **Consapevolezza dell'habitus** → al cambio di contesto (pesce fuori dall'acqua)

# Introduzione: società, individui, istituzioni — Schema
Il mondo delle istituzioni · Sessione 01

## Il modulo

- **Interrogativi** → cosa sono le istituzioni? / come leggere individui-società?
- **Doppia lente** → controllo (normativa) · protezione (solidale)
- **Certificazione** → <span class="c-warn">doppia sufficienza esame + seminario</span>

## Istituzione

- **Senso comune** → apparato di interesse pubblico (scuola, ospedale, tribunale)
- **Senso sociologico** → <span class="c-def">modello di comportamento con cogenza normativa</span>
  - più ampio → linguaggio, fidanzamento, tabù dell'incesto
  - più preciso → serve elemento normativo vincolante
- **Accezioni** → ente istituito per un fine · ordinamento (legge/tradizione)

## Costruzione sociale

- **Tesi** → <span class="c-tesi">istituzioni sembrano naturali, sono costruite</span>
- **Prova** → confronto tra contesti (<span class="c-es">matrimonio</span>)
- **Inerzia istituzionale** → resistenza alle novità + deresponsabilizzazione
  - ⚠️ rischio → utenti anonimi

## Berger & Luckmann: genesi delle istituzioni

- **Apertura al mondo** → istinti non specializzati → l'uomo produce se stesso
- **Ordine sociale** → produzione umana continua
- **Abitualizzazione** → azione ripetuta → schema fisso → meno scelte
- **Tipizzazione reciproca** → <span class="c-def">azioni X da attori X = istituzione</span>
  - condizioni → storia + controllo intrinseco
  - <span class="c-es">A e B: "ecco che ricominciamo"</span>
- **Trasmissione** → "così si fanno queste cose" → **oggettività**
- **Legittimazione** → giustifica l'ordine ai nuovi
- **Controllo sociale** → sanzioni, secondarie
- **Sedimentazione** → esperienza → linguaggio → tradizione

| Momento | Formula |
|---|---|
| Esteriorizzazione | <span class="c-tesi">società = prodotto umano</span> |
| Oggettivazione | <span class="c-tesi">società = realtà oggettiva</span> |
| Interiorizzazione | <span class="c-tesi">uomo = prodotto sociale</span> |

- **Reificazione** → società vista come cosa naturale

## Immaginazione sociologica

- **Definizione** → <span class="c-def">problemi personali = questioni sociali</span>
- **Mills** → biografia + storia
- **Funzioni**
  - smonta il "naturale"
  - smonta stereotipi → contro discriminazione
  - smonta senso comune → dipende dal contesto
  - domande non scontate
- **Esempi** → <span class="c-es">COVID-19 · Maria e Robert</span>

## Contesti sociali

- **Contesto sociale** → influenza della società sull'individuo
- **Neonati in maternità** → chance diverse
  - famiglia · quartiere · scuola · organizzazioni · lavoro
  - paese · periodo storico · identità
- **Sociologia** → studio dei contesti in cui le vite prendono forma

| Interazione sociale | Struttura sociale |
|---|---|
| agire insieme | <span class="c-def">regole → modelli durevoli</span> |
| norme | gerarchie/ruoli + norme/istituzioni |

- <span class="c-impl">interazione ⇄ struttura</span>
- **Strutture** → invisibili · limiti + opportunità
- **Istituzioni durevoli** → famiglia, scuola, ospedale psichiatrico, carcere, esercito, sistema legale, mercato, Stato

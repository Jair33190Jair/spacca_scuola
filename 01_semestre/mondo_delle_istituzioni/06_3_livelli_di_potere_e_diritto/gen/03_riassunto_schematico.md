# Il potere — Schema
Il mondo delle istituzioni · Sessione 06

## Potere

- **Potere** → <span class="c-def">capacità di ottenere risultati, realizzare o impedire cambiamenti rilevanti</span>
  - non solo coercizione → persuasione, influenza, autorità, legittimazione
  - visibile ↔ invisibile
  - attori → individui · gruppi · istituzioni
- **Legittimazione** → Stato = <span class="c-def">monopolio legittimo della forza</span>

## Tre dimensioni (Lukes)

| # | Dimensione | Meccanismo | Esempio |
|---|---|---|---|
| 1 | **Potere visibile** | conflitto aperto, risorse, misurabile | <span class="c-es">guerra, elezioni</span> |
| 2 | **Controllo dell'agenda** | decide cosa si discute → <span class="c-def">assenza di conflitto</span> | <span class="c-es">suicidio, stranieri senza voto</span> |
| 3 | **Manipolazione delle percezioni** | dominati interiorizzano la visione dominante | <span class="c-es">ruoli di genere, meritocrazia</span> |

- Visibilità: 1 → 2 → 3 decrescente; efficacia crescente
- **Risorse ↔ capitali**
  - denaro → economico
  - status → simbolico
  - accesso istituzioni → sociale
  - cultura → culturale
- **3ª dimensione** → auto-limitazione · auto-esclusione · auto-colpevolizzazione
- <span class="c-warn">⚠️ Non complottismo</span> → potere pervasivo, anche dentro di noi

## Bourdieu

- **Dominazione** → <span class="c-def">relazione asimmetrica duratura; visione dominante = naturale e universale</span>
  - asimmetria di potere
  - legittimazione invisibile
  - interiorizzazione
  - riproduzione sociale → scuola, famiglia, media
  - nessuna coercizione
- **Violenza simbolica** → <span class="c-def">potere dolce, invisibile, via simboli e linguaggio</span>
  - efficace quanto più è invisibile
  - si appoggia su **habitus** e **campo**
  - ambiti → scuola · lavoro · moda · accento · urbanistica · genere · disabilità

## Foucault

- **Potere** → si esercita, non si possiede; rete di relazioni
  - capillare · produttivo · anonimo · legato al sapere
- **Normalizzazione** → normale vs deviante → correggere, rieducare
- **Sorveglianza** → controllo continuo invisibile → conformità
- **Società disciplinare** → controllo interiorizzato
  - istituzioni: scuola, ospedale, carcere, <span class="c-warn">servizi sociali</span>

## Foucault vs Bourdieu

| Foucault | Bourdieu |
|---|---|
| **come** si esercita | **chi** lo esercita e **perché** è accettato |
| rete diffusa, anonima | struttura sociale: campi e capitali |
| produttivo | riproduttivo |
| auto-sorveglianza | habitus |

## Lavoro sociale

- **Riconoscere il potere** → non riprodurre disuguaglianze
- **Colloquio** → modulare il linguaggio sui capitali dell'utente
- **Co-progettazione** → non decidere al posto dell'utente
- **Obiettivo** → <span class="c-tesi">potere al servizio dell'emancipazione</span>

# Lo Stato moderno e le istituzioni — Schema
Il mondo delle istituzioni · Sessione 02

## Istituzione

- **Istituzione** → <span class="c-def">regole di comportamento stabili e sistematiche di una comunità</span>
  - non solo apparati: matrimonio, feste, linguaggio
- **Costruzione sociale e storica** → varia tra società e nel tempo
- **Controllo** → sanzioni + norme interiorizzate (socializzazione)

## Stato moderno

- **Monopolio fiscale** → solo lo Stato preleva imposte
- **Monopolio della violenza** → solo lo Stato usa la forza
- <span class="c-warn">Tendenze ideali, mai totali</span>

## Industrializzazione

- **1ª rivoluzione** → meccanizzazione + sistema di fabbrica
- **2ª rivoluzione** → elettricità + motore a combustione
- → **urbanizzazione** → **istituzionalizzazione** (scuole, eserciti, ospedali, manicomi, prigioni)

## Le tre istituzioni

| | Prima | Dopo |
|---|---|---|
| **Scuola** | privata, religiosa, élite | <span class="c-def">pubblica, obbligatoria, gratuita, laica</span> |
| **Ospedale** | religioso, per tutti i bisognosi | civile, solo malati |
| **Carcere** | attesa della pena, aperto | <span class="c-def">pena principale, chiuso, recupero</span> |

### Scuola
- **Condorcet** → istruzione primaria per tutti; uguaglianza di opportunità
- **Scolarizzazione di massa** → obbligo fino a 16 anni
- **Gellner** → uno-a-uno (agricola) vs **eso-istruzione** (moderna)
  - <span class="c-tesi">monopolio dell'istruzione > monopolio della violenza</span>

### Ospedale e manicomio
- **Separazione** → <span class="c-tesi">assistenza ≠ cura</span>
- **Diritto alla salute** → XX secolo
- **Pinel** → libera gli alienati dalle catene
- **Antipsichiatria** (Basaglia) → contro coercizione e separazione
- **De-istituzionalizzazione** → chiusura manicomi e istituti

### Carcere
- **Beccaria** → pena pubblica, pronta, necessaria, minima, proporzionata, legale
- **Howard** → carceri salubri, celle individuali
- **Bentham** → Panopticon: vedere senza essere visti
- **Foucault** → <span class="c-tesi">dal corpo all'anima</span>
  - supplizio → regolamento
  - potere-sapere, normalizzazione
- **Ignatieff** → carcere moderno compiuto nel 1877

## Senso dell'istituzionalizzazione

- **Progresso o controllo?** → <span class="c-tesi">ambivalenza</span>
  - protezione → crescita, cura
  - normalizzazione → normale vs deviante, esclusione
- **Istituzione totale** (Goffman) → spoliazione dell'identità
- **Costruzione sociale** → <span class="c-impl">si può interrogare e trasformare</span>

# La socializzazione: la famiglia e la scuola — Schema
Il mondo delle istituzioni · Sessione 04

## Perché socializzare

- **Animali** → istinti innati, trasmessi geneticamente
- **Umani** → pochi istinti, grande apprendimento, lungo adattamento
- **Socializzazione** → <span class="c-def">diventare parte della società + trasmissione culturale tra generazioni</span>
  - sopperisce al bagaglio istintuale
  - canalizza gli istinti
  - dinamica: famiglia → gruppi → comunità
  - canali: **linguaggio** + **esempio**

## Berger e Luckmann: il ciclo

| Tappa | Formula | Esempio |
|---|---|---|
| **Esteriorizzazione** | <span class="c-def">società = prodotto umano</span> | butta la minestra / nuovo saluto |
| **Oggettivazione** | <span class="c-def">società = realtà oggettiva</span> | «il cibo non si butta» / «così si fa» |
| **Interiorizzazione** | <span class="c-def">uomo = prodotto sociale</span> | non la butta più / saluto "normale" |

- **Socializzazione** → agisce soprattutto nell'interiorizzazione → **identità sociale**
- **Normale ≠ naturale** → costruzione sociale, quindi modificabile
- **Reificazione** → <span class="c-def">prodotti umani visti come cose naturali</span>
  - grado estremo dell'oggettivazione
  - di istituzioni, ruoli («non ho scelta»), identità

## Mead: sviluppo del sé

- **Identità** → non innata, nasce dall'interazione
- **Io / me / sé** → definizioni nel manuale
  - **me** ≈ **io sociale** (B&L) → parte dell'io fatta di tipizzazioni sociali
- Tappe:
  - **Imitazione** → copia senza regole
  - **Play** → assume ruoli adulti
  - **Game** → conosce i ruoli di tutti
- **Altro generalizzato** → <span class="c-def">atteggiamento della società interiorizzato</span>
  - 🟠 biblioteca: silenzio spontaneo
  - 🟠 guardie e ladri, portiere

## Ruoli e legittimazione (lettura)

- **Ruolo** → tipizzazione condivisa da un gruppo
- Ruoli **rappresentano** le istituzioni → giudice = legge
- Ogni ruolo → conoscenze, norme, valori, emozioni
- **Distribuzione sociale della conoscenza** → generale vs specialistica
- **Legittimazione** → <span class="c-impl">necessaria per trasmettere ai nuovi</span>
  - vocabolario → proverbi → teorie → universi simbolici

## Tipi di socializzazione

| Tipo | Contenuto |
|---|---|
| **Primaria** | competenze di base: cognitiva, normativa, espressivo-simbolica |
| **Secondaria** | competenze e ruoli per scuola, lavoro, associazioni |
| **Anticipatoria** | valori di un gruppo desiderato |
| **Alla rovescia** | i giovani educano i vecchi |
| **Risocializzazione** | nuove regole nelle istituzioni totali |

- ⚠️ <span class="c-warn">primaria e secondaria ≠ fasi distinte → dura tutta la vita</span>

## Agenzie di socializzazione

- famiglia · scuola · gruppi · media · organizzazioni
- **Famiglia** → prima agenzia, affettiva
- **Scuola** → interagire, appartenere a un gruppo, identità sociale
  - sezioni maschile/femminile → ruoli di genere
  - Baroncelli → dislessia ieri ignorata, DSA oggi difesa con un avvocato

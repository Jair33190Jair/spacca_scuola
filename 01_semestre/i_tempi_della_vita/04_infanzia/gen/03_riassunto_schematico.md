## Freud: sviluppo psicosessuale

- **Metodo** → ricostruzione a posteriori (après-coup), da adulto a bambino
- <span class="c-def">**Pulsione (Trieb)** → spinta energetica al confine psiche/corpo</span>
  - **Libido** → manifestazione dinamica della pulsione sessuale
  - **Eros** → pulsione di vita
  - **Thanatos** → pulsione di morte
- **Stadi psicosessuali** → fasi di organizzazione della libido intorno a zone erogene

| Stadio | Età | Zona | Tema chiave |
|--------|-----|------|-------------|
| Narcisismo primario | Nascita | — | Sé totale |
| **Orale** | 0-2 aa | Bocca | Incorporazione, introiezione |
| **Sadico-anale** | 18 m-4 aa | Ano/viscere | Trattenere/espellere, controllo |
| **Fallico-uretrale** | 3-5 aa | Genitali | Potenza narcisistica |
| **Edipo** | ~4 aa | — | Triangolo, limite, differenze |
| **Latenza** | 6-12 aa | — | Rimozione, apprendimento |
| **Genitale** | Pubertà | — | Integrazione pulsioni |

- **Sottofasi (K. Abraham)**:
  - **Orale libidica** → piacere / **Orale aggressiva** → post-dentizione
  - **Anale espulsiva** → espellere / **Anale ritentiva** → trattenere
- **Fissazione** → blocco energetico a uno stadio
- **Regressione** → ritorno a funzionamento più antico sotto stress
- <span class="c-tesi">**Complesso di Edipo** → da relazione duale → triangolare; struttura Io/Es/Super-Io</span>
- <span class="c-warn">**Complesso di Elettra** (Jung) → versione femminile; Freud: invidia del pene → posizione fallocentrica superata</span>

## Il bebè e la relazione primaria

- **Bebè immaginario** → rappresentazione consapevole (ecografie, parametri medici)
- **Bebè fantasmatico** → proiezioni inconsce, transgenerazionali
- **Bebè reale** → temperamento proprio, ritmicità biologica
- <span class="c-def">**Nidazione bio-psichica** (Missonier) → contenimento somatico + affettivo in gravidanza</span>

### Compiti del neonato alla nascita

- **Integrazione dei ritmi** → veglia/sonno, fame/sazietà, azione/riposo
- <span class="c-def">**Sincronizzazione polisensoriale** → ≥ 2 canali sensoriali sincronizzati per percepire la realtà</span>
- **Regolazione arousal** → livello di vigilanza del SNC
  - Regolazione interattiva → controllata dall'adulto
  - Autoregolazione → controllata dal bambino (distogliere lo sguardo, addormentarsi)

### Mediatori adulti

- <span class="c-def">**Rêverie materna** (Bion) → la madre dà significato all'esperienza grezza del bambino</span>
- <span class="c-def">**Mirroring** (Fonagy) → rispecchiamento vivo e coerente</span>
- <span class="c-tesi">**La relazione dà forma al cervello**: ossitocina/dopamina → costruzione sinaptica; cortisolo → distruzione sinaptica</span>
- **Frustrazione moderata** → necessaria per differenziare Sé dall'oggetto (Freud)
- <span class="c-impl">**Mismatch + riparazione** (Tronick) → la madre risponde il 27% delle volte; le dissincronie riparate sono motori dello sviluppo</span>
- <span class="c-es">**Faccia immobile** (Still Face) → esperimento: bambino tenta il recupero, poi si ritira → base per comprendere la riparazione</span>

## Winnicott: ambiente facilitante

- <span class="c-tesi">**"There is no such thing as a baby"** → il bebè esiste solo nella coppia</span>
- **Preoccupazione materna primaria** → identificazione empatica fisiologica; fare le cose *sufficientemente bene (good enough)*

| Pilastro | Descrizione |
|----------|-------------|
| <span class="c-def">**Holding**</span> | Sostenere fisicamente → primi confini del Sé, coesione psicosomatica |
| <span class="c-def">**Handling**</span> | Cure corporee → primi significati affettivi |
| <span class="c-def">**Object Presenting**</span> | Presentare l'oggetto nel momento del bisogno → onnipotenza transitoria |

- **Dipendenza assoluta** → **De-accomodamento** → frustrazione sana → oggetti reali (amati e odiati)
- <span class="c-def">**Oggetto transizionale** → primo possesso "non-me"; area intermedia soggettivo/oggettivo</span>
- **Capacità di essere solo** → maturità emotiva; dipende da oggetto interno buono

## Teoria dell'attaccamento: Bowlby e Ainsworth

- <span class="c-tesi">**Attaccamento = fatto primario** (non derivato dalla nutrizione)</span>
  - Prova: imprinting (Lorenz), esperimenti Harlow sui macachi
- <span class="c-def">**Attaccamento** → sistema innato; ricerca prossimità per sicurezza</span>
- **Accudimento** → sistema complementare nell'adulto

### Condizioni per parlare di legame di attaccamento

- Legame **duraturo** (non transitorio)
- Con una **persona specifica**
- **Emotivamente significativo**
- Orientato alla **ricerca di sicurezza e conforto**

### Caratteristiche del sistema

- **Neotenia** → immaturità prolungata; sistema di attaccamento molto sviluppato e duraturo
- <span class="c-def">**Monotropismo** → legame preferenziale con una figura</span>
- **Attivazione** → stress, separazione, malattia, paura
- **Disattivazione** → raggiunta la sicurezza

### Funzioni del legame (Principio D)

- **Ricerca di prossimità** → sicurezza fisica e percepita
- **Porto sicuro** → regolazione emotiva nei momenti di angoscia
- **Base sicura** → piattaforma per l'esplorazione e l'autonomia

### Modelli Operativi Interni (MOI)

- Pattern cognitivo-affettivi costruiti dall'esperienza
- Multipli, contesto-dipendenti
- Operano al di fuori della coscienza
- <span class="c-impl">Agiscono come filtro percettivo delle relazioni</span>

## I quattro pattern di attaccamento (Strange Situation)

| Pattern | % | Caregiver | Regolazione | Attenzione |
|---------|---|-----------|-------------|------------|
| **Sicuro** | 50% | Sintonizzato | Autonoma + diadica | Flessibile |
| **Evitante** | 25% | Distanziante | Autonoma | Fissata sul gioco |
| **Ansioso/ambivalente** | 10% | Preoccupato | Diadica (inefficace) | Fissata sul caregiver |
| **Disorganizzato** | ~15% | Spaventante/spaventato | Compromessa | Disorientata |

- <span class="c-warn">**Disorganizzato** → "la fonte di sicurezza è la fonte di paura" (D. Hill)</span>
  - Risposte: Freeze / Fight / Flight
- <span class="c-impl">Evitante e ambivalente = **soluzioni di compromesso** (pattern insicuri strutturati)</span>

## Attaccamento nel ciclo di vita e separazione

- <span class="c-tesi">**Dalla culla alla tomba** (Principio F) → MOI stabili ma modificabili</span>
- **Attaccamento sicuro** → risorsa di resilienza (Principio G)
- **Attaccamento insicuro** → fattore di vulnerabilità; rischi per salute mentale e relazioni

### Risposta alla separazione (Principio H)

| Fase | Descrizione |
|------|-------------|
| **Protesta** | Ricerca attiva, pianto, rabbia |
| **Disperazione** | Ritiro passivo, tristezza |
| **Distacco** | Apparente indifferenza — difesa, non guarigione |

## Attaccamento e cultura

- Teoria biologica universale ma con **varianti culturali**
- Germania del Nord → più evitante
- Kibbutz israeliani → più ambivalente
- <span class="c-es">Dogon (Mali) → 81% sicuro, 0% evitante</span>

## Trasmissione intergenerazionale

- AAI madre → predice SS del figlio
- <span class="c-warn">Attaccamento disorganizzato → fattore di rischio psicopatologico (Greenberg, Fonagy)</span>
- Relazioni correttive possibili: maestre, allenatori, nonni, terapia

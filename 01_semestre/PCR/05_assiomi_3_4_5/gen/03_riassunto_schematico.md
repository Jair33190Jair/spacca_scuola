# Le 4 orecchie e il terzo, quarto e quinto assioma — Schema
Processi Comunicativi e Relazionali · Sessione 05

## Le 4 orecchie (Schulz von Thun)

| Lato | Emittente (lingua) | Destinatario (orecchio) |
|------|--------------------|-------------------------|
| **Contenuto** | Cosa dico | Cosa mi dici |
| **Rivelazione di sé** | Come mi vedo | Che immagine dai di te |
| **Relazione** | Come ti vedo | Come mi vedi |
| **Appello** | Cosa ti chiedo | Cosa mi chiedi |

- **Destinatario** → <span class="c-def">traduce</span> secondo le sue premesse
- **Orecchio diverso** → risposta diversa
- **Lingua ≠ orecchio** → fraintendimento
- **Uscite** → metacomunicare · non verbale congruente · traduzione ≠ verità

## 3° assioma — Punteggiatura

- **Punteggiatura** → <span class="c-def">da dove ciascuno fa iniziare la sequenza</span>
  - "siccome tu… allora io…" → causa → effetto lineare
- **Circolarità** → nessun inizio; ogni comportamento è causa ed effetto
- **Disturbo** → conflitto da punteggiature differenti
  - una sola descrizione della realtà: la mia
- **Domande sistemiche** → presente e futuro, non colpe
- **Soluzione** → metacomunicazione

## Profezia che si autoavvera

- **Definizione** → aspettativa che si avvera tramite i comportamenti
- **Effetto Pigmalione** → aspettative positive → prestazioni migliori
- **Effetto Golem** → aspettative negative → prestazioni peggiori
- **Operatore** → aprire possibilità, obiettivi raggiungibili

## 4° assioma — Numerico / analogico

| | Numerico | Analogico |
|---|---|---|
| Forma | Verbale | Non verbale |
| Esprime | <span class="c-def">Contenuto</span> | <span class="c-def">Relazione</span> |
| Legame con la cosa | Arbitrario | Somiglianza |
| Limite | Povero sulla relazione | Ambiguo, niente "non" |

- **Il come classifica il cosa** → il non verbale metacomunica
- **Incongruenza** → disorientamento, blocco
- ⚠️ <span class="c-warn">Mehrabian → solo messaggi incongruenti su emozioni</span>

## 5° assioma — Simmetria / complementarità

| | Simmetrica | Complementare |
|---|---|---|
| Base | Uguaglianza | Differenza |
| Posizioni | Pari | One-up / one-down |
| Comportamenti | Si rispecchiano | Si completano |
| Disturbo | <span class="c-warn">Escalation</span> | <span class="c-warn">Rigidità</span> |

- **Valore** → nessuno di per sé; coesistono e si alternano
- **Professionista** → <span class="c-tesi">complementare up, flessibile</span>
  - mai simmetrico
  - troppa asimmetria → dipendenza, niente empowerment
- **Stop all'escalation** → mettersi down (strategia) · metacomunicare
- **Rigidità complementare**
  - irrigidimento ruoli → dipendenza / abuso di potere
  - inversione dei ruoli → conflitto, rottura

# Il sistema di premesse e gli approcci teorici — Schema
Processi Comunicativi e Relazionali · Sessione 01

## 1. Percezione

- **Stimoli/informazioni** → **filtri** (selezione) → **significato** → risposta
- **Significato** → <span class="c-def">valore attribuito da chi percepisce ed elabora</span>
- **Filtri** → percezione, esperienze, educazione, conoscenze, valori, visione del mondo
- Significato → emozione → **comportamento**
- **Legittimare** → la reazione dell'altro ha senso per lui

## 2. Sistema di premesse

- **Micro-teorie** → credenze implicite dall'infanzia → diventano **lenti**
  - modificabili oppure **impermeabili**
  - obiettivo: **consapevolezza**, non cambiare le lenti
- **Sistema di premesse** → <span class="c-def">mappa cognitiva ed emotiva</span>
  - collettivo: credenze, stereotipi, pregiudizi, norme, valori condivisi
  - personale: esperienze, significati, conoscenze, aspettative
  - fonti: linguaggio, famiglia, scuola, media, relazioni
  - funzione: identificare, etichettare, classificare, dare valore
- **La mappa non è il territorio** → <span class="c-tesi">la realtà non si conosce mai direttamente</span>
- **Valutare comportamenti** → non bollare la persona
- **Comprendere ≠ giustificare** → l'altro è altro da me

## 3. Approcci teorici

| Approccio | Autore / data | Nucleo |
|---|---|---|
| Psicoanalisi | Freud, 1896 | inconscio, rimozione, Es/Io/Super-Io · <span class="c-warn">non d'esame</span> |
| Comportamentismo | Watson 1913 · Skinner '50-'60 | <span class="c-def">black box</span>, S → R, causalità lineare |
| Cognitivismo | '50-'60 → oggi | Input → Mente → Output, H.I.P. |
| Pre-costruttivismo | Piaget ('50-'70) | assimilazione / accomodamento |
| Pre-costruttivismo sociale | Vygotskij ('20-'30) | linguaggio, zona di sviluppo prossimale |
| Costruttivismo | Kelly ('50) | costrutti personali permeabili |
| Costruzionismo sociale | Gergen | realtà costruita socialmente, sé relazionale |
| Sistemica | Bateson, Morin | elementi in interazione, causalità circolare |

- **Condizionamento classico** → associazione di stimoli (Pavlov, piccolo Albert)
- **Condizionamento operante** → rinforzo (Skinner box)
  - rinforzo positivo > punizione
  - comportamento non rinforzato → **estinzione**
- **Realtà di primo ordine** → <span class="c-def">il dato condiviso</span> ("è una sedia")
- **Realtà di secondo ordine** → <span class="c-def">i significati attribuiti</span> ("è comoda")
  - <span class="c-warn">non relativismo assoluto</span>: le lenti competenti sono più definite
  - nella pratica i due ordini sono sempre impastati
- **Costruttivismo vs costruzionismo** → costruzione individuale vs costruzione sociale e relazionale

## 4. Gergen (lettura)

- **Costruzione sociale** → reale = accordo sociale, non "nulla esiste"
- **Linguaggio** → azione nelle relazioni, non fotografia
- **Giochi linguistici / forme di vita** → Wittgenstein
- **Fatti = valori** → nessuna descrizione neutra
- **v minuscola vs V maiuscola** → verità locali vs assolute → pluralismo radicale
- **Azione supplementare** → il significato nasce nella relazione
- **Sé relazionale** → "sé mediante l'altro"

## 5. Sistemica

- **Ricompone** invece di scomporre
- **Concetti** → complessità, totalità, interdipendenza, retroazione
- **Causalità circolare** → <span class="c-def">ogni comportamento è causa ed effetto</span>
- **Osservatore** → <span class="c-tesi">fa parte del sistema, nessuna neutralità</span>
- **Significati** → co-costruiti nella relazione
- Ragazzo diverso a scuola e a casa → sistemi diversi, nessuna contraddizione

| DA | A |
|---|---|
| Energia | Informazione |
| Sistema chiuso | Sistema aperto |
| Intrapsichico | Comunicazione / interrelazioni |
| Causalità lineare | Causalità circolare |
| Poco contesto | Contesto centrale |
| Passato | Presente |
| Interpretazione | Cambiamento |

## 6. Operatore sociale

- Premesse → **favoriscono / disturbano** la relazione
- **Relazione** → prerequisito dell'intervento
- **Comportamento = comunicazione** → osservare = ascoltare
- **Pregiudizi** → difficili da modificare (conferme) → profezia che si autoavvera, Pigmalione, Golem
- **Stereotipo** → impronta rigida
- **Guardare → osservare** → riconoscere i propri schemi
- **Auto-osservazione**
  - premesse, stile relazionale, coinvolgimento emotivo, aspettative
  - <span class="c-warn">si acquisisce solo nella pratica</span>

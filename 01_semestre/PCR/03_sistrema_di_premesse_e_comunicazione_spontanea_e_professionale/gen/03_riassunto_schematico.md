# Sistema di premesse, comunicazione spontanea e professionale — Schema
Processi Comunicativi e Relazionali · Sessione 03

## Sguardo sistemico (ripresa)

- **Sistema / contesto** → li definisce l'osservatore
- **Sguardo meta** → guardare come guardo
- **Prima il problema** → poi le soluzioni ("no *solving* senza *problem*")
- **Domande sistemiche** → elementi, regole, relazioni, ruoli, risorse, rete
  - la mia relazione col sistema
  - altri sistemi dell'utente
  - cosa mi serve ancora sapere
- **Omeostasi** → spingere il cambiamento provoca retroazione negativa
  - <span class="c-es">nonna che vieta le gite</span> → interlocutore giusto + rete
  - <span class="c-es">moglie che rifiuta la casa di cura</span> → cambiamento graduale
- **Macro** → incide sul lavoro; **advocacy** nel codice deontologico

## Chi è l'altro?

- <span class="c-tesi">**L'altro** → esiste solo nella relazione con me, qui e ora</span>
- Relazione = incontro tra **sistemi di premesse**
- **Circolarità** → responsabilità + potere di cambiare ciò che metto io

## Catena del significato

- **Percezione → filtro → significato → azione → retroazione**
  - filtro = idee, emozioni, intenzioni, opinioni, visione del mondo
  - sequenza circolare, senza inizio
- <span class="c-dato">**Dispersione 70%**</span> → verificare, ripetere, chiarire

## Tre aspetti della comunicazione

| Aspetto | Studia | Esempio |
|---|---|---|
| **Sintassi** | regole e struttura delle frasi | rapporti scritti chiari |
| **Semantica** | significato delle parole | "casa" = abitazione |
| **Pragmatica** | <span class="c-def">effetti sui comportamenti</span> | "fa caldo" → apro la finestra |

## Significato e feedback

- <span class="c-def">**Il significato lo dà il ricevente**</span>, non l'emittente
- <span class="c-tesi">**Significato = risposta (feedback)**</span>
- **Metacomunicazione** → comunicare sulla comunicazione
- **Co-costruzione** → significati sociali e relazionali, variabili nel tempo
- **Comunicazione = comportamento = interazione = relazione** (in sistemica)
- **Metafora architettonica** → comunicando costruiamo spazi da abitare

## Spontanea vs professionale

| Spontanea | Professionale |
|---|---|
| <span class="c-def">automatismo non filtrato</span> | <span class="c-def">consapevole</span> |
| ignora feedback e obiettivi | attenta a retroazioni e obiettivi |
| emozioni e obiettivi personali | emozioni governate, cura della relazione |
| rischi: malintesi, conflitti, sfiducia | limiti: non posso cambiare l'altro |

- **Supporti** → équipe, intervisione, supervisione

## Operatore sociale

- **Artigiano della relazione** → relazione su misura, progettata, non standardizzabile
- **Competenze**
  - richiesta e aspettative
  - regole, possibilità, limiti del servizio
  - obiettivi concreti, realistici, realizzabili
  - gestione delle proprie emozioni
  - <span class="c-tesi">relazione > successo personale</span>
- **Atteggiamenti** → conoscere le proprie premesse, auto-osservarsi, descrivere senza etichette, flessibilità, mediazione
- <span class="c-def">**Governo dei contesti relazionali**</span> → ascolto reciproco → significati condivisi

## Esercitazione naufragio

- Cane → premesse valoriali
- Telo / cucina → influenzamento per competenza
- Sestante → scartato per ignoranza
- Oggetti → riflettono obiettivi (restare vs essere salvati)
- Soddisfazione alta anche cambiando idea → "noi"
- Fragilità riconosciute → obiettivi di miglioramento

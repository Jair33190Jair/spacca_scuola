# Gli errori comunicativi dell'operatore sociale — Schema
Processi Comunicativi e Relazionali · Sessione 06

## Definizione

- **Errore comunicativo** → <span class="c-def">disturbo introdotto dall'operatore nella relazione</span>
- **Chi sbaglia** → <span class="c-warn">solo il professionista</span>; utente = disturbi, genitore = responsabilità
- **Conseguenze** → perdita di credibilità e fiducia
- **Posizione** → complementare up accettata; responsabilità sempre dell'operatore

## Patologie degli assiomi

| Assioma | Patologia |
|---|---|
| 1° | <span class="c-def">Squalificazione</span>, rifiuto, sintomo |
| 2° | Confusione livelli; <span class="c-def">disconferma</span> ≠ rifiuto |
| 3° | Punteggiatura discordante, profezia che si autoavvera |
| 4° | Errori di traduzione analogico → numerico |
| 5° | Escalation simmetrica, complementarità rigida |

- **Metacomunicazione** → uscita dai circoli viziosi
- **Paradosso** → "sii spontaneo"

## Casi

- **AS rientro a scuola** → determinismo, sarcasmo, troppo up → escalation
- **Luca** → famiglia esclusa → totalità ignorata → retroazione negativa → accusa → disconferma
  - correttivo: <span class="c-impl">"cosa non ho ancora visto?"</span>
- ***My name is Joe*** → cambio argomento → squalificazione + disconferma
  - correttivo: <span class="c-tesi">legittimare + metacomunicare</span>

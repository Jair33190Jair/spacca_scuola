# Primo e secondo assioma della comunicazione — Schema
Processi Comunicativi e Relazionali · Sessione 04

## Assiomi

- **Assiomi** → 5 caratteristiche strutturali, sempre presenti insieme
- **Pragmatica** → effetti della comunicazione sul comportamento
- **Scopo** → vedere la comunicazione → governarla

## 1° assioma

- <span class="c-def">**Non si può non comunicare**</span> → ogni comportamento è comunicazione
  - nessun "non-comportamento"
  - indipendente dalle intenzioni
  - rifiuto di comunicare = comunicazione
- **Significato** → attribuito dal destinatario (contesto, premesse, relazione)

| Risposta | Cosa fa |
|---|---|
| **Rifiuto** | nega di voler comunicare |
| **Accettazione** | risponde in modo coerente |
| <span class="c-warn">**Squalificazione**</span> | risposta vaga/incongruente → svaluta il contenuto |
| **Esibizione del sintomo** | si sottrae con un malessere |

## Contesto

- **Contesto** → luogo, persone, relazioni, ruoli, regole, cultura, premesse
- **Determina il significato** → marca di contesto
- **È regolativo** → comportamenti attesi / da evitare
- **Ridondanza** → ripetizione → rivela la regola

| Regola | Definizione |
|---|---|
| Esplicita | dichiarata |
| Implicita | non detta, condivisa |
| Di base | violazione grave |
| Secondaria | violabile |
| <span class="c-def">Meta-regola</span> | come cambiare le regole, chi decide |

## Disturbi

- **Effetto** → comunicazione da legame a ostacolo
- <span class="c-warn">**Professionista**</span> → disturbo = errore
- **Premesse differenti** → legittimare
- **Contesto fisico** → rumore, luce, spazio, tempo
- **Contenuto** → gergo, confusione, vaghezza → anche disconferma
- **Contesto relazionale**
  - differenti marcature
  - slittamento di contesto
- **Relazione**
  - squalificazione letta come disconferma
  - confusione contenuto / relazione → lotta su chi decide
  - paradossi → doppio legame

## 2° assioma

- <span class="c-def">**Contenuto + relazione**</span> → la relazione classifica il contenuto
- **Contenuto** → cosa → notizia → verbale
- **Relazione** → come → comando → soprattutto non verbale
- <span class="c-tesi">**Il come prevale sul cosa**</span>
- **Metacomunicazione** → comunicazione sulla comunicazione

## Proposta relazionale

- **Definizione del sé** → "ecco come mi vedo"
- **Definizione della relazione** → "ecco come vorrei che ti ponessi"

| Risposta | Significato |
|---|---|
| <span class="c-def">Conferma</span> | accetto la tua definizione |
| Rifiuto giudicante | sull'identità → "sei…" |
| Rifiuto non giudicante | sul comportamento → "fai…" |
| <span class="c-warn">Disconferma</span> | non esisti → la più dolorosa |

- <span class="c-tesi">**Regola**</span> → molte conferme, rifiuti sul comportamento, zero disconferme
- **Coincidente** → relazione confermata
- **Non coincidente** → rifiutata / disconfermata → rinegoziare
- **Clima** → co-costruito da proposte e risposte

## Marcature di contesto

- **Verbali** → cortesia, appellativi
- **Para-verbali** → tono
- **Non verbali** → distanza, postura, contatto
- **Fisiche** → ufficio, bar, disposizione

## Paradossi

- **Messaggio paradossale** → due contenuti incompatibili
- **Metacomunicazione incongruente** → contenuto ≠ relazione
- **Ingiunzione paradossale** → "Sii spontaneo!"
- <span class="c-def">**Doppio legame**</span> → contraddizione in relazione vitale, nessuna uscita
- **Uscita** → metacomunicare verbalmente

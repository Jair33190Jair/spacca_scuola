# L'approccio sistemico — Schema
Processi Comunicativi e Relazionali · Sessione 02

## Sguardo sistemico

- **Domanda guida** → "Ho visto tutto? Cosa non ho ancora visto?"
- **Fotografia** → <span class="c-warn">etichetta fissa che impedisce di vedere il cambiamento</span>
- **Persona** → sempre inserita in sistemi (famiglia, scuola, amici, servizi, équipe)
  - contesto a matrioska: Ticino → Svizzera → Europa
  - operatore + utente = almeno 2 sistemi
- **Sistemico** ≠ <span class="c-warn">sistematico</span> (sistematico = organizzato)
- **Epistemologia** → modo di guardare centrato su relazioni e comunicazioni
- **Complesso vs complicato**
  - complicato → spiegabile scomponendo (orologio)
  - complesso → mai conoscibile del tutto (puzzle infinito)

## Origini

- **Teoria dei sistemi + cibernetica** → feedback, omeostasi, autoregolazione
- **Bateson** → comportamenti spiegati dai fenomeni comunicativi
- **Palo Alto** → 3 filoni: comunicazione · cambiamento · terapia
- **Terapia familiare (MRI)** → <span class="c-tesi">patologia sistemica, non individuale</span>
- **"La relazione viene prima"** → l'identità nasce dalle relazioni

## Competenze dell'operatore

- **"Si comporta", non "è"** → bandire la copula, niente etichette
- **Ogni comportamento ha un senso** → comprenderlo prima di giudicare
- **Logica lineare** → causa → effetto → colpevole
- **Logica circolare** → azioni/retroazioni, ognuna causa ed effetto
- **Consapevolezza** → cosa fanno succedere circolarmente le comunicazioni
- **Strategie** → con quale obiettivo agisco
- **Governare** → timone + responsabilità; cambiamento negoziato
- **Manipolare** → <span class="c-warn">agire a proprio beneficio</span>
- **Non interpretare** → no diagnosi psicologiche; approccio complementare ad altri

## Sistema

- **Definizione** → <span class="c-def">elementi interconnessi: cambia uno → cambiano tutti e il sistema</span>
- **Contesto** → fenomeno inspiegabile senza contesto (volpi ↔ conigli)

| Fattore | Definizione |
|---|---|
| **Elementi** | le persone |
| **Interazioni** | comunicazioni circolari, interne e con il contesto ("motore") |
| **Attributi** | <span class="c-warn">comportamenti, non qualità</span> |
| **Ruoli** | funzioni + posizioni di potere |
| **Regole** | esplicite · implicite · <span class="c-def">meta-regole</span> |

## Proprietà

| Proprietà | Definizione | Implicazione |
|---|---|---|
| **Totalità** | non sommatività; tutto inscindibile | spostare un membro cambia tutto il gruppo |
| **Omeostasi** | mantenere l'equilibrio preesistente | <span class="c-warn">se rigida → disfunzionale</span> |
| **Autoregolazione** | equilibrio senza immobilità | risposta tramite retroazioni |
| **Omeostasi dinamica** | alternare retroazioni − e + | richiede <span class="c-def">"è possibile modificare le regole"</span> |
| **Equifinalità** | esito indipendente dalle condizioni iniziali | no determinismo; qui e ora |

- **Retroazione negativa** → frena il cambiamento → stabilità
  - solo negative → irrigidimento
- **Retroazione positiva** → amplifica il cambiamento → trasformazione
  - solo positive → instabilità, disgregazione
- <span class="c-warn">− / + non sono giudizi di valore</span>
- **Paradosso del cambiamento** → <span class="c-tesi">più spingo, più resiste → accompagnare, co-costruire</span>

## Contesti e modello ecologico

- **Ogni sistema** → contesto del livello inferiore + sottosistema del superiore
- **Microsistema** → interazioni dirette
- **Mesosistema** → insieme dei microsistemi del soggetto
- **Esosistema** → contesti di cui almeno uno è esterno al soggetto
- **Macrosistema** → istituzioni, valori, cultura
- **Campo dell'operatore** → micro + meso
  - ruoli, regole, punti di vista → criticità → risorse (cercate insieme)

## Lavoro sistemico

- **Sguardo "meta"** → di 2° livello: come guardo io?
- **Fase 1** → definire il problema con domande (vincoli, tempo, errore possibile)
- **Fase 2** → cercare soluzioni
  - <span class="c-warn">errore classico: saltare la fase 1</span>
- **Domande** → persone · regole · relazioni · ruoli · valori · problema · obiettivi · ostacoli · risorse · rete · mia relazione · altri sistemi dell'utente · "ho visto abbastanza?"
- **Sistema che resiste** → cosa lo blocca? · ho contribuito io? · cosa posso fare?

## Dalle letture

- **Regola di relazione** → accordo, spesso implicito, sulla natura del rapporto
- **Quid pro quo** → scambio che regge la diade; crisi mai causata da uno solo
- **Sintomo** → può proteggere il rapporto
- **Coalizione** → due contro un terzo; triangolo perverso
- **Mito familiare** → credenza condivisa = sistema di difesa della famiglia
- **Omeostasi familiare** → il paziente migliora → i familiari peggiorano
- **Pragmatica** → effetti della comunicazione sul comportamento
- **Comunicazione = comportamento**
- **Informazione, non energia** → sasso vs cane
- **Ridondanza** → schemi ripetuti da cui dedurre le regole
- **Metacomunicazione** → comunicare sulla comunicazione
- **Scatola nera** → osservare input/output, non la mente
- **"A quale scopo?"** → al posto di "perché?"

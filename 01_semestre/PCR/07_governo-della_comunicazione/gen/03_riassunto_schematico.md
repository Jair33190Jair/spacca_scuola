# Il governo della comunicazione — Schema
Processi Comunicativi e Relazionali · Sessione 07

## Cornice

- **Meta-competenza** → governare la comunicazione in ogni contesto
  - **Consapevolezza** → cosa faccio, quali effetti circolari
  - **Strategie** → con quale obiettivo, cosa è opportuno
- **Cambiamento** → solo con condivisione e cooperazione
  - <span class="c-tesi">Mai **sopra**, **contro**, **senza** l'altro</span>
  - nessuna soluzione senza problema · l'aiuto non si impone
- **Legittimare** punto di vista → ≠ dare ragione
- **Rispetto** → guardare di nuovo · opposto = disconferma
- **Relazione sufficientemente buona** → obiettivo prioritario
- **Auto-osservazione** → "telecamera" su di sé

## Strategie

| Strategia | In breve |
|---|---|
| **Esplorazione** | Conoscere il sistema con domande; <span class="c-warn">≠ indagare</span> |
| **Domande** | Riflessive: fanno vedere, riflettere, cambiare |
| **Influenzamento** | Reciproco; ≠ manipolazione |
| **Ascolto attivo** | Relazione: "tu per me esisti" |
| **Feedback** | Bussola per ricalibrare; conferme + rifiuti non giudicanti |
| **Valorizzazione** | Conferma di <span class="c-def">comportamenti</span> positivi, non identità |
| **Legittimazione** | Validare <span class="c-def">emozioni</span> senza correggerle |
| **Linguaggio** | Chiaro, ordinato, adeguato, semplice |
| **Metacomunicazione** | Congruente (non verbale) + verbale (chiarire) |
| **Autorevolezza** | Regolare con la partecipazione dell'altro |
| **Flessibilità** | Passo indietro → stop escalation simmetrica |
| **Assertività** | Messaggi-io |
| **Dire di no** | Legittimazione + no + motivazione/alternativa |
| **Equidistanza** | Mediatore non schierato |
| **Giusta distanza** | Né troppo coinvolto né distaccato |
| **Empatia** | Ascolto profondo + risonanza + differenza |
| **Exotopia** | Altro come me e diverso da me |

## Ascolto

- **Passivo** → distratto → disconferma
- **Oppositivo** → ascolto per controbattere
- **Attivo** → azioni:
  - contesto fisico · parole e non verbale · non ignorare affermazioni disturbanti
  - sospendere giudizi · legittimare · feedback non verbali
  - domande · spazio · silenzio · riassumere

## Feedback dell'operatore

- **Conferma** → "ti vedo, vali"
- **Rifiuto non giudicante** → comportamenti osservabili
  - <span class="c-warn">"ti comporti da arrogante" = "sei arrogante"</span>
  - no "sempre", "mai"
- **Legittimare le proprie emozioni** → auto-osservazione, intervisione, supervisione

## Metacomunicazione verbale

- chiarire **termine** → "strano = particolare"
- chiarire **tono** → "scherzavo"
- chiarire **intenzione** → "non volevo criticarti"
- **chiedere** chiarimenti → "sei arrabbiato o infervorato?"
- → uscita da 4 orecchie e doppio legame

## Assertività

- **Passività** → reprimere → frustrazione
- **Aggressività** → imporre → rottura
- **Assertività** → esprimere con rispetto
- **Messaggio-io** → comportamento → "io mi sento" → richiesta

## Dire di no

- legittimazione + no + motivazione
- apprezzamento + no + motivazione
- legittimazione + no + alternativa
- legittimazione + no + nostro punto di vista → <span class="c-es">"sono un disastro"</span>

## Empatia

- <span class="c-warn">"Nei panni dell'altro" → impossibile, rischio giudizio</span>
- Risuonare ≠ provare la stessa emozione
- **Exotopia** → come me (valore) + diverso da me (prospettiva)

- **4° assioma** → analogico/digitale
